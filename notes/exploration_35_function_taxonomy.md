## 0. 입력 없고 출력만? 출력 없이 입력만?

**프로그래밍 세계**에서는 4가지 조합이 다 있지만, **수학 함수는 정의상 "입력 → 출력"** (각 입력에 정확히 하나의 출력을 대응):

| 조합 | 프로그래밍 예 | 수학 함수인가 | autograd 그래프에? |
|---|---|---|---|
| 0입력 → 1출력 | 상수, `time.now()` | 상수 함수로 치면 O (시계는 X — 같은 입력 다른 출력) | Variable 리프가 사실 이 역할 (아래) |
| 1입력 → 0출력 | `print(x)`, 로깅 | X (사이드 이펙트 — 프로시저) | ❌ 못 들어옴 |
| 0입력 → 0출력 | `sleep(1)` | X | ❌ |
| n입력 → m출력 | 일반 함수 | O (m=1이 전형) | ✅ DeZero Function |

- **autograd가 요구하는 것**: 같은 입력에 같은 출력을 내는 순수 함수 (Determinacy). `print` 같은 사이드 이펙트는 그래프의 부적합자 — 역전파할 "계산"이 없으니까.
- ★ **DeZero의 특수 케이스 — Variable 리프**: `x = Variable(np.array(2.0))`은 creator가 없는 그래프의 원점. "0입력 → 1출력 함수"(상수)처럼 행동해. 그래프의 리프는 전부 이것 — 데이터가 함수인 척 들어와 있는 모양새다.
  - ★ **"리프" 용어 기억법 (브로 질문, 2026-08-25)**: leaf/root는 **역전파 방향 기준 트리**의 위치 — root = loss(역전파 시작점), leaf = 입력 변수(역전파 종착점). PyTorch `is_leaf`와 동일 관례 (grad_fn/creator 없는 노드). 세 가지 기억법:
    1. **리프 = 끝방** — 계산이 처음 시작하는 끝이자 gradient가 마지막 도착하는 끝 (같은 노드의 두 방향에서 본 모습 — 순전파에선 시작의 끝, 역전파에선 도착의 끝).
    2. **리프 = 그래프와 세상의 경계** — creator가 없다 = 이 값을 만든 계산이 그래프 안에 없다 = 그래프 밖(사용자/데이터셋)이 데이터를 건네는 입구. gradient가 여기까지만 오고 더 갈 곳이 없는 이유.
    3. **rezero 안방 용어 연결** — `fill_grad` 에러 메시지의 "입력 변수(원점)". 원점 = 리프 = leaf, 세 단어 같은 것. 역전파 방향 한 줄: **root(loss)에서 leaf(입력)로.**
- 참고: 파이썬 관점의 이 이야기는 [탐구 노트 16 (부작용/순수 함수)](./exploration_16_side_effect.md)에서 이미 깊게 다룸 — 여기선 "그래프 참여 자격" 요약만.

## 1. 일변수 → 일변수 (R → R)

**문제없다 — 그리고 1고지의 세계 그 자체다.**

- Square, Exp, Sin... 전부 이 모양. 도함수 $f'(x)$도 스칼라.
- 야코비안은 1×1 — "행렬이 안 보이는" 이유 (탐구 34 §3 shape 지도).
- 다변수로 가는 확장 경로가 두 갈래라는 게 함정 (step34 혼란의 씨앗):
  - **(a) 벡터화** — linspace 200개: 사실 R→R 함수 200개의 병렬 (탐구 34 §7 두 관점)
  - **(b) 진짜 다변수** — R²→R: 입력 성분이 진짜로 조합됨 (아래 §2)

<a id="q2"></a>
## 2. 다변수 → 일변수 (Rⁿ → R) — "간섭"의 두 층위

브로 질문: *"다변수 입력 간에 출력 산출을 위한 전혀 간섭이 없는 경우와 있는 경우? 이외의 경우?"*

**"간섭"을 두 층위로 쪼개야 정리된다** — 이게 이 노트의 첫 번째 정밀화:

### 층위 A: 출력이 여러 입력을 조합하는가?

Rⁿ→R이면 **조합은 필연**이다 — 출력이 하나니까 모든 기여가 한 곳으로 모인다. sum의 야코비안이 $(1, 1, \ldots, 1)$인 것처럼. 그러니 "조합 여부"로 나누면 전부 간섭 있음이 되어 버려 구분이 무의미.

### 층위 B: 도함수가 형제 입력을 필요로 하는가? ★ 진짜 구분 축

| 도함수 모양 | 예 | ∂y/∂x₀ | backward 구현 |
|---|---|---|---|
| **각자 따로** (간섭 X) | $y = x_0^2 + \sin(x_1)$ | $2x_0$ — x₀만으로 계산 | 입력의 순수 함수 (D1 지도 ②형) |
| **각자 따로 (상수)** | $y = x_0 + x_1$ | $1$ | 아무것도 안 봄 (①형) |
| **형제 필요** (간섭 O) | $y = x_0 \cdot x_1$ | $x_1$ — 형제 값 필요! | self.inputs 클로저 캡처 (③형) |
| **출력 필요** | $y = \sigma(x_0 + x_1)$ | $y(1-y)$ — forward 출력 재사용 | self.output 참조 (④형) |

즉 브로가 느낀 "간섭"의 정체 = **층위 B**, 그리고 그 답은 이미 D1 지도의 4유형이다. "이외의 경우" = ④ 출력형 (질문 5에서 다시 만남).

- 수학 표기로 보면: Rⁿ→R의 야코비안은 1×n **행벡터** — "대각/비대각" 구분 자체가 없음 (탐구 34의 대각 논의는 Rⁿ→Rⁿ 이야기). n→1에서는 "어떤 성분이 0이 아닌가"만 있을 뿐.
- 실전 예: loss 함수가 전형적 Rⁿ→R (모든 파라미터 → 스칼라 손실).

<a id="q3"></a>
## 3. 다변수 → 다변수 (Rⁿ → Rᵐ) — 섞음의 패턴

여기서야 "대각/비대각"이 의미를 가짐 (탐구 34 §3·§7 회수). **섞음의 패턴 = 야코비안의 희소 패턴**이라는 관점이 열쇠:

| 패턴 | 야코비안 모양 | 예 |
|---|---|---|
| **완전 대각** (안 섞음) | 대각행렬 | element-wise: sin, ReLU, 덧셈 브로드캐스트 |
| **부분 희소** (국소 섞음) | 띠 모양 (밴드) | ★ 합성곱 (Conv) — 이웃 픽셀만 섞음, 원거리는 0 |
| **축소** (n→m, m<n) | 세로로 긴 직사각 | 신경망 층 (784→10), pooling — 완전 밀집이면 dense |
| **치환** (재배치) | 치환행렬 (행/열 1개씩) | transpose, reshape — 값 계산 없이 위치만 이동 |
| **완전 밀집** | 0이 거의 없음 | softmax (야코비안 $\text{diag}(s) - ss^{T}$), 완전연결층 |

- **합성곱의 효율성이 여기서 나온다** — 야코비안이 밴드(희소)라서 "다 섞는" 행렬곱 대신 국소 연산으로 backward 가능. CNN이 im2col로 밀집행렬곱 풀면 희소성을 포기하고 대신 BLAS 속도를 취하는 트레이드오프 (5고지 step55~57 예고).
- softmax처럼 **출력들끼리 엮이는** 함수도 이 범주 — 정규화라 모든 입력이 모든 출력에 영향.

## 4. 수학 함수가 아닌 것들 — 구조 연산 (4고지에서 브로가 만난 것들)

*"수학 함수 말고 입출력 상황 특성을 고려해 순전파/역전파를 구현해서 유용하게 쓰는 것?"* — 네, **구조 연산(structural ops)**이 있고, 신경망 구현의 절반이 이것들이다:

| 연산 | 순전파 | 역전파 (국소 VJP) | 성격 |
|---|---|---|---|
| `sum` | n개를 더해 축소 | **gy를 모든 입력에 복사** | 축소 ↔ 확장 |
| `broadcast_to` | 값을 축 방향으로 복제 | 늘어난 축을 따라 **sum** | ★ 확장 ↔ 축소 |
| `reshape` | 형상 변경 | 같은 재배열 (역 reshape) | 치환 |
| `transpose` | 축 교환 | 같은 교환 (역 transpose) | 치환 |
| `get_item` | 슬라이싱 | 뽑힌 자리에 gy 배치, 나머지 0 | 선택 |

★ **멋있는 대칭**: `sum`의 역전파는 `broadcast`(복사)이고, `broadcast`의 역전파는 `sum`(취합)이다 — 서로가 서로의 역방향. "늘린 것은 줄여서 돌려주고, 줄인 것은 늘려서 돌려준다."

- 왜 가능한가: 이것들은 값 계산이 아니라 **값의 재배치**인데, 재배치도 선형 사상이라 VJP가 정의됨 (탐구 34 §11 — reshape/transpose의 야코비안은 치환행렬, 만들지 않고 "역 재배치"로 계산).
- 왜 유용한가: **shape 맞추기 게임** (탐구 34 §10)의 실전 도구들. 신경망에서 `y = xW + b` 하나 치더라도 b의 브로드캐스팅, 배치 차원의 reshape가 다 이것들. "수학(미분 공식) 없이도 그래프 참여 가능"이 구조 연산의 존재 증명.

## 5. 역전파가 참조하는 것 — 스펙트럼과 hook의 국경선

브로 질문: *"역전파 시 순전파의 입력/출력이 사용되는 조합? 입력만 / 출력만 / 둘 다 / 아예 안?"*

**그 답이 스펙트럼이다** — 참조하는 것이 왼쪽에서 오른쪽으로 갈수록 "멀어진다":

```
① 아무것도 안 봄      ② 자기 입력      ③ 형제 입력        ④ forward 출력     ⑤ upstream gradient
   (상수 도함수)        (순수 관습)      ★ hook의 마지노선   (캐시 재사용)      ★★ hook의 세계 밖
   Add(1), Neg(-1)     Square(2x)      Mul(x1), Div       Tanh(1-y²)        MatMul(gy·Wᵀ)
                                       Tanh 재호출형       Exp(exp=exp)
```

| 유형 | 참조 대상 | rezero 관습 | 비고 |
|---|---|---|---|
| ① 상수형 | 없음 | 인자 무시 (`lambda _:`) | "자명해도 검증" — Neg 버그 교훈 |
| ② 입력형 | 자기 입력 x | **관습 준수** (hook 인자만) | 가장 깨끗 — Square, Sin, Pow |
| ③ 다른 입력형 | 형제 입력 (self.inputs) | ★ 관습 위반 — 클로저 캡처 | 수학적 필연 (§2 층위 B). v2에선 2차 미분 자동 연결 |
| ④ 출력형 | forward 출력 y (self.output) | 재호출/재사용 **전략 선택** (Config.reuse_output) | y는 weakref 소멸 가능 + exp' = exp 같은 계산 절약 |
| ⑤ upstream형 | gy 자체 | ❌ hook 불가 — **backward 직접 오버라이드** | MatMul의 gx = gy·Wᵀ. 4고지부터 |
| (+ 파라미터형) | 가중치 (xᵀ·gy의 xᵀ) | backward 직접 (⑤와 세트) | gW = xᵀ·gy — ③+⑤ 조합 |

- **둘 다 쓰는 경우** (질문의 "둘 다"): ②+④ = 입출력형 (D1 지도 ⑤, 노트 32의 SiLU) — 입력 x와 출력 y를 동시에 참조. 4고지+ 활성함수에서 등장 예고. 위 표에 ⑤로 밀린 D1 ⑤기호와 헷갈리지 말 것 — D1 지도의 ⑤(입출력형)는 이 표의 ②+④ 조합이고, 이 표의 ⑤(upstream형)는 D1 지도 바깥의 새 영역이다. (기호가 겹쳐서 나중에 정리 필요 — 초안 메모)
- **아무것도 안 쓰는 경우** (질문의 "안"): ① 상수형이 정확히 그것. "참조 없음 = 도함수가 상수" — 그리고 그 재미분 결과가 None이 되는 특성까지 step34에서 실증했지.
- **국경선의 의미**: ①~④까지는 `derivative()` hook으로 표현 가능 (부모가 `df(x) * upstream` 곱셈을 대행). ⑤부터는 곱셈 형태 자체가 아니므로 hook이 무의미 — backward를 통째로 사람이 쓴다. 이 스펙트럼이 4고지를 읽는 눈.

<a id="muldiv"></a>
## 6. Mul/Div 재방문 — 질문 2와 질문 5가 만나는 지점

브로 머리 꼬임의 복선 정리:

1. **질문 2의 "간섭"**을 층위 B(도함수가 형제를 필요로 하는가)로 정밀화하면 — Mul/Div가 바로 "간섭 있는" 부류. Add/Sub는 "간섭 없는" 부류. 이 구분은 부정확한 직관이 아니라 **D1 ③형 vs ①②형의 구분 그 자체**였다.
2. **질문 5의 "참조 조합"**으로 보면 — Mul/Div는 "자기 입력 말고 형제 입력을 참조"하는 유형. 스펙트럼 ③.
3. 종합: Mul/Div의 "문제"는 버그가 아니라 **스펙트럼상 마지노선(③)에 서 있다는 것**. 관습(②까지 순수)을 벗어났지만 아직 hook 영토 안 — 클로저 캡처라는 실용적 타협으로 재배치. 그리고 4고지 MatMul이 스펙트럼 ⑤에 도착하면서 hook 영토가 끝나고 backward 직접 구현의 시대가 열림.

> 한 줄 요약: **"간섭(섞음)은 함수의 성질이고, 참조는 backward 구현의 성질 — Mul은 간섭하는 함수라 참조가 형제로 흘렀을 뿐, 둘은 같은 이야기의 두 얼굴이다."**
