## 0. 한 장 요약 — fill_grad 하나가 차수를 결정

> **fill_grad는 도구가 하나일 뿐 — 어떤 그래프를 주느냐가 차수를 결정한다.**
> - `fill_grad(y)` → 1층(원본)을 순회 → **1계 미분** (f')
> - `fill_grad(gx)` → 2층(1계 미분식)을 순회 → gx를 미분 → gx가 f'였으니 **2계 미분** (f'')
> - `fill_grad(gxx)` → 3계... (tanh 폭증의 길)

"2계 미분 기능"을 따로 구현한 게 아니라, **"미분 = 그래프 소유 계산"이라는 성질 하나가 차수를 무한대로 열어준 것.** 노트 30 3단 논법(미분은 계산이다 → 계산은 그래프를 남긴다 → 남은 그래프는 재미분 가능)의 실체. (브로 발견, 2026-08-26)

<a id="원본과미분"></a>
## 1. 원본 그래프와 미분의 관계 — 브로 최종 정리 (2026-08-26)

> 브로: *"최초 순전파가 만드는 그래프는 미분 이전의 원본 계산 그래프. 1차 역전파는 그 오리지널 그래프를 통해 1계 미분을 계산. 이때 create_graph=True로 진행하면 완료 시점에 '역전파 계산 자체의 그래프' = 1계 미분 계산 식이 존재. 여기서 2차 역전파를 때리면 1계 미분 식을 다시 1계 미분하는 것 — 결과적으로 원본에 대한 2계 미분."*

전부 정확. 수식 대응:

| 단계 | 그래프 | 계산 | 결과 |
|---|---|---|---|
| 순전파 | **1층** (원본: x → Square → y) | y = f(x) = x² | y.data = 4.0 |
| 1차 역전파 | 1층을 순회 + **2층 생성** | gx = f'(x) = 2x | gx.data = 4.0 (eval까지 완료) |
| 2차 역전파 | 2층을 순회 | (f')' = f'' | x.grad = 2.0 |

★ 핵심: **1차 역전파는 eval까지 완료하는 실행이었다** — 그래프만 만든 게 아니라 값(gx.data=4.0)까지 계산. 노트 33 "모든 실행은 그래프를 낳는다"의 반대 명제 — 그래프를 낳은 그 실행은 평가였다. (브로 발견)

<a id="이중정체"></a>
## 2. gx의 이중 정체

> 브로: *"백프랩의 일종의 순전파 아닌가? 근데 gx는 x의 grad잖아? grad가 Variable이란 소리고?"*

| 관점 | gx의 정체 |
|---|---|
| **x 입장** | x.grad 슬롯에 저장된 것 (1차 미분 결과) |
| **2층 그래프 입장** | 2층의 **최종 출력 Variable** — 1층에서 y가 하던 역할을 그대로 이어받음 |

- **"1차 역전파 = 2층의 순전파"** — 1차 역전파를 실행하는 순간 그 계산 자체가 2층 그래프를 순전파한 것.
- `gx = x.grad`는 "x의 grad 슬롯에서 Variable을 꺼내 gx라는 이름으로 참조하겠다"는 사용자 코드 — 이 순간 사용자 참조가 생겨 2층 그래프 생존 보장.
- gx와 x의 관계: **직접 참조 아님** — `gx.creator → Mul(2) → t1 → Mul(1) → x`로 creator 사슬을 타고만 닿음.

<a id="슬롯생애"></a>
## 3. grad 슬롯의 생애 — 중간의 자동 처분, 리프의 면책

> 브로: *"중간 순회 시 중간 변수의 grad는 전부 초기화되는데, 리프 단은 순회 과정에서 초기화 부분이 없다?"*

코드 구조 (`fill_grad`의 `output.grad = None`은 **output에만** 적용):

| | 중간 변수 grad | 리프 grad |
|---|---|---|
| 정체 | 소비 끝난 **임시값** | 역전파의 **최종 산물** |
| 자동 처분 | O (output.grad=None) | **X — 자동 초기화 경로 자체가 없음** |
| 비우는 주체 | 프레임워크 | 사용자 (clear_grad) |

- 리프가 어떤 f의 output이 **될 수 없는 위치** (inputs 쪽에만 존재)라 루프가 못 건드림.
- clear_grad를 x에만 하는 이유: 2차 결과를 받을 슬롯이 x.grad 하나 (y.grad는 이미 버려짐, 중간들도 버려짐) + 안 비우면 누적 오염 (`gx + f''`).
- 리프/중간 판정은 **그래프 구조 기준**(creator 있느냐)이지 사용자 참조 여부가 아님 — 중간 변수를 사용자가 들고 있어도 retain_grad=False면 버려짐.
- create_graph=True여도 중간 슬롯의 값은 버려짐 — "값은 버려도 식은 2층에 남는다".

<a id="신생재참조"></a>
## 4. 신생 vs 재참조 — 미분식이 명단을 정한다

> 브로: *"미분 결과가 생성하는 함수는 새로운 함수 객체가 맞나? 변수 부분은 재참조되는 부분이 있다?"*

- **함수 객체는 전부 신생** — `mul(x, 2)` 호출마다 `Mul()` 새 인스턴스.
- y=x²의 2층 구성원: 옛 객체 재등장은 **x 하나**, 나머지(c2, gy, t1, gx, Mul들) 전부 이번 역전파에서 신생.
- **어떤 옛 변수가 재등장하나는 미분식 성분(노트 32 유형 지도)이 결정**:

| 도함수 유형 | 재등장하는 옛 변수 |
|---|---|
| ① 상수형 (Add) | 없음 |
| ② 입력형 (Square: 2x) | 자기 입력 x |
| ③ 형제 의존 (Mul: x₁) | 형제 입력들 |
| ④ 출력형 (Tanh 재사용: 1-y·y) | **forward 출력 y** |

- ★ 합성 함수가 오면 **중간 출력도 재등장** — sin(x²)의 미분 cos(x²)·2x에서 cos가 참조하는 건 x가 아니라 1층 중간 출력(x² Variable). → 후보 12 실험 예정.
- 브로 초기 질문 "x만 재활용?"의 답: y=x² 예시가 입력형이라 x만 보였을 뿐 — 일반 규칙은 "직전 층을 구성하는 부품 전부가 재등장 후보, 명단은 미분식이 정함".

<a id="gy생존"></a>
## 5. gy의 생존 조건

- gy = Variable(ones_like)는 fill_grad 내부에서 태어나 **사용자 참조 없음**.
- create_graph=True → 2층이 참조해 생존 (Mul(2).inputs의 강한 참조).
- False(기본) → 순회 계산 중에만 쓰이고, retain_grad=False면 y.grad에서조차 버려져 계산 후 GC.
- "상수 1조차 2층 그래프의 리프" (core.py 주석).

<a id="세가지"></a>
## 6. data · grad · output — 세 가지는 전부 다르다

> 브로: *"2층의 최종 출력 Variable의 output과 grad에 모두 값이 저장되는 상황인가?"*

gx 하나를 놓고 보면 (답: **저장은 data뿐**):

| 필드 | gx에서의 상태 | 비고 |
|---|---|---|
| **data** | 4.0 | ★ 유일한 값 저장 — 1차 역전파가 계산 |
| **grad** | None → 2차 때 씨앗 1 잠깐 → 버려짐 | gx도 누군가의 output이라 자동 처분 대상 |
| **output** | gx의 필드가 **아님** | `Mul(2).output = weakref(gx)` — 남이 나를 참조하는 관계 |

- "식을 소유"의 구현 = `creator != None` (+ 사슬로 전체 복원 가능).
- "식이 살아있다"의 구현 = creator→inputs 강한 참조 사슬이 그래프를 GC로부터 보호 (gx 하나로 2층 전체 생존).

표현 사전:

| 노트 표현 | 구현 |
|---|---|
| "식을 소유" | `creator != None` |
| "값을 소유" | `data`에 숫자 |
| "식이 살아있다" | 참조 사슬이 GC로부터 보호 중 |

<a id="대칭"></a>
## 7. 순방향 output / 역방향 grad — 대칭 구조

> 브로: *"순방향의 출력 변수는 output이고 역방향의 출력 변수는 grad란 게 이제야 감이 오면서 여전히 헷갈린다."*

| | 순전파 | 역전파 |
|---|---|---|
| 입력 | 리프들 (x) | **1** (씨앗, y에서 출발 — 곱셈 항등원) |
| 출력 | **y** (명시적 반환) | 리프들의 grad 필드에 **흘어져 기록** (반환 없음 — fill_grad는 None) |

- 역전파의 결과는 `local * upstream`로 **새 Variable**을 만들어 상대 함수의 **입력 변수 .grad 슬롯에 대입** — "출력의 저장 위치가 grad 필드"인 것.
- 이 대입은 **그래프 밖의 코드**(fill_grad의 배분 단계)가 수행 — 그래프가 아니라. (UML 04 리뷰에서 확정)
- 순전파 "여러 입력 → 하나의 출력", 역전파 "하나의 씨앗 → 여러 리프로 흩어짐" — 뒤집힌 거울.
