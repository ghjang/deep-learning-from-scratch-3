<a id="tldr"></a>
## 🎯 TL;DR

한국어 "미분"이라는 단어 하나가 **최소 7가지 의미**로 쓰인다. 영어는 용어가 분리되어 있어 헷갈림이 적은 반면, 한국어는 한 단어로 다 뭉개버림.

★ 핵심 생존 전략: **문맥 신호 5가지**로 해독하자 (§4 참고):

| 신호 | 해독 |
|---|---|
| 뒤에 숫자/특정 점 | 미분값 (숫자) |
| "$X$의 미분" + $X$가 함수 | 도함수 (함수) |
| "미분하다" 동사 | 미분 연산 수행 |
| $\dfrac{dy}{dx}$, $f'$ 기호 등장 | 도함수 컨텍스트 |
| "가능하다" 붙으면 | 미분 가능성 (differentiable) |

→ **기초 부족이 아니다. 한국 수학 용어 번역의 구조적 문제다.** 영어 원서를 볼 때가 오히려 의미가 더 명확하게 들어오는 이유이기도 하다.

<a id="7개의미"></a>
## 1. 핵심 진단 — "미분"이란 단어 하나에 7개 의미

한국 수학 교재에서 "미분"이 등장하면 다음 7가지 중 하나일 확률이 높다:

| # | 문맥 예시 | 실제 의미 | 수학적 대상 |
|---|---|---|---|
| 1 | "이걸 **미분**하자" | 미분 **연산** 수행 (동사) | 과정 |
| 2 | "$x=3$에서 **미분값**" | 특정 점에서의 결과값 | 숫자 (실수) |
| 3 | "$f$의 **미분**은 $2x$" | **도함수** $f'$ | 함수 |
| 4 | "$f$의 **미분**을 구하라" | 도함수를 구하라 | 함수 |
| 5 | "**미분식** $\dfrac{dy}{dx}=2x$" | 미분을 포함한 수식 | 방정식 |
| 6 | "**미분** 가능하다" | differentiable (형용사) | 성질 |
| 7 | 학문명 "**미분**학" | differential calculus | 학문 |

★ 7가지가 전부 **"미분"**이라는 같은 단어/어근. 문맥 없이는 도저히 구분 불가. 브로가 헷갈리는 게 당연하다.

### 가장 빈번한 혼돈: 도함수 vs 미분값

특히 헷갈리는 건 #3, #4 (도함수) vs #2 (미분값):

```
"f(x) = x²의 미분은 2x"        ← 여기 "미분" = 도함수 (함수)
"x=3에서 미분은 6"              ← 여기 "미분" = 미분값 (숫자)
```

같은 단어인데 **하나는 함수, 하나는 숫자**. 이게 브로가 직면한 헷갈림의 핵심.

<a id="어원비교"></a>
## 2. 어원 비교 — 한국 vs 영어, 왜 이렇게 됐나

### 영어는 용어가 분리되어 있다

| 한국어 | 영어 | 명확도 |
|---|---|---|
| "미분하다" (동사) | **differentiate** | ✅ 분리 |
| "도함수" (함수) | **derivative (function)** | ✅ |
| "미분값" (특정 점 결과) | **derivative value** / **slope** | ✅ 분리 |
| "미분" (연산/과정) | **differentiation** | ✅ |
| "미분가능하다" | **differentiable** | ✅ |
| "미분학" | **differential calculus** | ✅ |
| "미분 방정식" | **differential equation** | ✅ |

→ 영어는 **differentiate**(동사) / **derivative**(결과) / **differentiation**(과정) 으로 명확히 나뉜다.

### 한국어는 왜 이렇게 뭉개졌나

**번역의 역사적 사고** 추정:

1. "differential calculus" → **미분학(微積分學)** 으로 번역 (微=작을 미, 分=나눌 분 → "잘게 나눈다" = 미분)
2. 여기서 **"미분(微分)"** 이라는 어근이 분리되어 나옴
3. 이후 derivative, differentiate, differentiation, differentiable 등 **모든 derivative 계열 용어를 "미분"으로 번역** (게으른 번역)
4. 유일하게 **도함수 (導函數)** 라는 정확한 단어가 따로 있지만, 일상 표현에선 "미분"으로 흔히 부름

→ 결과: 하나의 어근이 7개 의미를 덮어버리는 용어 재앙 발생.

### 微分(미분)의 한자 어원

```
微 (미, 작을 미) — "아주 작은", "미세한"
分 (분, 나눌 분) — "나누다"
```

→ **"아주 작게 나눈다"** = 미분. Leibniz의 $\dfrac{dy}{dx}$ 직관(미소 변화량의 비)을 번역한 것.

★ 어원 자체는 Leibniz 표기법의 직관과 잘 맞음. 문제는 **그 단어 하나에 너무 많은 의미를 쑤셔넣은 것**.

<a id="해독휴리스틱"></a>
## 3. ★ 해독 휴리스틱 5가지 (실전 가이드)

브로가 책을 읽을 때 "미분"이 나오면 이 5가지 신호로 의미를 해독하자:

### 휴리스틱 1: 뒤에 숫자/특정 점이 있으면 → 미분값

```
✅ "x=3에서의 미분은 6"          → 미분값 (숫자 6)
✅ "이 점에서의 미분"             → 미분값
✅ "x=2 일 때 미분"               → 미분값
```

### 휴리스틱 2: "$X$의 미분" + $X$가 함수 → 도함수

```
✅ "f(x)=x²의 미분은 2x"          → 도함수 (함수 2x)
✅ "이 함수의 미분을 구해라"       → 도함수 구하라
✅ "sin의 미분은 cos"             → 도함수
```

★ 이 경우 "$X$의 미분"은 영어 "derivative of $X$"와 같음. derivative = 도함수.

### 휴리스틱 3: "미분하다" 동사 → 미분 연산 수행

```
✅ "이걸 미분하자"                → 미분 연산 수행
✅ "양변을 미분해라"              → 미분 연산 수행
✅ "미분해 보자"                  → 미분 연산 수행
```

### 휴리스틱 4: 수학 기호 등장 → 컨텍스트 확인

```
✅ "f'(x) = 2x"                   → f' 기호 = 도함수
✅ "dy/dx = 3"                    → dy/dx 기호 = 도함수 (or 미분값, 문맥 확인)
✅ "∇f"                           → 그래디언트 (편미분 벡터)
```

★ 기호가 **변수를 포함**하면 도함수, **숫자만**이면 미분값.

### 휴리스틱 5: "가능하다"/"불가능하다" → 미분 가능성

```
✅ "미분 가능한 함수"             → differentiable function
✅ "이 점에서 미분 불가능"         → not differentiable at this point
✅ "연속이어도 미분 가능하진 않다" → differentiability 이야기
```

### 종합 플로우차트

```
"미분" 등장
    │
    ├── 동사? ("미분하다")
    │       → 미분 연산 수행
    │
    ├── "가능/불가능"?
    │       → 미분 가능성 (differentiable)
    │
    ├── "$X$의 미분" + $X$가 함수?
    │       → 도함수 (derivative function)
    │
    ├── 특정 점/숫자 동반?
    │       → 미분값 (slope at point)
    │
    ├── 수식에 $f'$, $\dfrac{dy}{dx}$ 등 기호?
    │       → 기호가 변수 포함: 도함수
    │       → 기호가 숫자만: 미분값
    │
    └── 학문/분야? ("미분학", "미분방정식")
            → 학문명
```

## 4. 밑시딥 실전 예시 — 문장별 해독

밑바닥부터 시작하는 딥러닝 시리즈에서 실제 등장하는 패턴들 해독 연습:

### 예시 1: step04 (수치 미분)

```
책: "수치 미분으로 미분을 구해봅시다"
```

- "수치 미분" → numerical differentiation (방법론)
- "미분을 구해봅시다" → **도함수를 구하자** (함수)
- 해독: "수치적 방법으로 도함수를 구하자"

### 예시 2: step04 결과

```
책: "x=2에서의 미분값은 4.000000입니다"
```

- "미분값" → 명시적으로 "값"이라고 함 → **미분값 (숫자 4)** ✅ 명확

### 예시 3: step05 (역전파 이론)

```
책: "역전파는 국소적 미분을 전달합니다"
```

- "국소적 미분" → local derivative → **각 노드의 도함수** (함수)
- 해독: "각 노드가 자기 도함수를 계산해서 전달한다"
- → 탐구 #13 §8의 $\dfrac{df}{dx}$와 정확히 일치

### 예시 4: step07+ (역전파 구현) — * 살짝 스포일러*

> *참고: 이 예시는 아직 안 읽은 step07+ 내용을 앞서 언급함. step05 시점에선 "아, 나중에 이런 게 나오는구나" 정도로만 보고 넘어가도 OK.*

```
코드: x.grad = np.array(1.0)   # grad = 미분(값)
```

- 여기서 `grad`는 **미분값** (특정 변수에 대한 gradient)
- Variable 하나당 하나의 미분값. 함수 전체가 아니라 **특정 점에서의 미분값**

### 예시 5: 혼돈의 패턴 — *살짝 스포일러*

> *step07+ 학습 뒤에 더 체감될 패턴. step05 시점엔 가볍게 읽고 넘어가도 OK.*

```
책: "역전파를 통해 미분을 효율적으로 계산합니다"
```

이건 진짜 모호하다. 해독 시도:
- "미분을 계산합니다" → 미분값? 도함수?
- 맥락상 **"각 변수에 대한 미분값 (gradient)을 계산한다"** 가 정확
- → 모호하지만 신경망 컨텍스트에선 **gradient (미분값 벡터)** 를 의미하는 게 보통

★ 핵심: 신경망/딥러닝 컨텍스트에서 **"미분"은 대부분 gradient (미분값)을 의미**. 도함수 자체보다 결과값이 더 중요하기 때문.

## 5. 표기법 노트 #13과의 연결

탐구 #13에서 정리한 표기법 관점을 용어에 적용하면:

| 표기 | 가리키는 것 | 한국어 용어 |
|---|---|---|
| $\dfrac{dy}{dx}$ (변수 포함) | 도함수 | "도함수", 또는 "미분" (혼돈) |
| $f'(x)$ (변수 포함) | 도함수 | "도함수", 또는 "미분" (혼돈) |
| $\dfrac{dy}{dx}\bigg\vert_{x=3}$ (특정 점) | 미분값 | "미분값" |
| $f'(3)$ (특정 점 평가) | 미분값 | "미분값" |
| $\nabla f$ | 그래디언트 | "그래디언트", "기울기" |

★ 표기법 자체는 명확한데, **한국어 용어가 표기를 못 따라감**. 표기는 함수/값을 구분하지만, "미분"이라는 단어는 둘 다 덮어버림.

→ 그래서 **표기를 보고 의미를 파악하는 습관**이 중요. "미분"이라는 단어에 의존하지 말 것.

## 6. 전역 용어 지도 — 미분 관련 용어 전부

step05 이후 등장할 미분 관련 용어들을 미리 정리:

### 핵심 3종 (이 노트의 주인공)

| 한국어 | 영어 | 의미 | DeZero 대응 |
|---|---|---|---|
| **도함수** | derivative (function) | 미분 결과로 얻은 **새 함수** | (개념적) $f'$ |
| **미분값** | derivative value, slope | 특정 점에서의 **결과 숫자** | `Variable.grad` |
| **미분(연산)** | differentiation | 미분하는 **과정/연산** | `backward()` 호출 |

### ★ 핵심 통찰: 모든 미분 계열이 "함수 vs 값" 이원 구조 (브로 발견)

도함수/미분값뿐 아니라, **편미분·그래디언트도 동일한 이원 구조**를 가진다. 한국어에선 이 구분이 잘 안 드러나지만, 영어/수학 표기로 보면 명확하다:

| 개념 | "함수" (전체 규칙) | "값" (특정 점 평가) |
|---|---|---|
| **1변수 미분** | **도함수** $f'$ | **미분값** $f'(a)$ |
| **편미분** | **편도함수** $\dfrac{\partial f}{\partial x}$ | **편미분값** $\dfrac{\partial f}{\partial x}\bigg\vert_{(a, b)}$ |
| **그래디언트** (출력 스칼라) | **그래디언트** $\nabla f$ (벡터) | **그래디언트값** $\nabla f\bigg\vert_{\mathbf{a}}$ |
| **야코비안** (출력 다변수) | **야코비안** $\mathbf{J}$ (행렬) | **야코비안값** $\mathbf{J}\bigg\vert_{\mathbf{a}}$ (step41+ 텐서) |

★ 한국어 용어 함정:
- "미분" → 도함수? 미분값? (혼란, #14 주제)
- "편미분" → 편도함수? 편미분값? (같은 혼란)
- "그래디언트" → 그래디언트(함수)? 그래디언트값? (같은 혼란)

→ 세 용어 전부 **"함수 vs 값" 구분이 안 된 채** 통용. 문맥으로 해독해야 함.

★ 영어 원서가 유리한 지점: *partial derivative function* vs *partial derivative value* 식으로 명시적.

→ **신경망의 `p.grad`는 "그래디언트값" (특정 파라미터에서 평가한 숫자 벡터)** 이지, 그래디언트 **함수**가 아님. `loss.backward()`는 loss 함수의 그래디언트 **함수**를 계산한 뒤, 현재 파라미터 값에서 **평가**해 각 `p.grad`에 숫자 벡터로 저장.

### 파생 용어

| 한국어 | 영어 | 의미 |
|---|---|---|
| **편미분** | partial derivative | 다변수 함수에서 한 변수만 미분 |
| **그래디언트** | gradient | 모든 편미분을 모은 벡터 |
| **미분 방정식** | differential equation | 미분을 포함한 방정식 |
| **미분 가능성** | differentiability | 미분 가능한 성질 |
| **수치 미분** | numerical differentiation | 작은 차분으로 근사 미분 (step04) |
| **해석적 미분** | analytical differentiation | 공식으로 정확히 미분 |
| **자동 미분** | automatic differentiation (autodiff) | 코드로 정확히 미분 자동화 |
| **역전파** | backpropagation | 리버스 모드 autodiff |
| **국소적 미분** | local derivative | 각 노드의 자기 미분 (역전파 기본 단위) |

### ★ 딥러닝에서 자주 쓰는 "미분" = gradient

신경망 컨텍스트에서 **"미분을 구한다"고 하면 90%는 gradient를 의미**:

```python
loss.backward()    # ← 이 한 줄이 모든 파라미터의 "미분(gradient)"을 계산
for p in model.parameters():
    p.grad         # ← 이게 "미분값" (각 파라미터에 대한 loss의 미분)
```

→ 딥러닝에서는 미분 **결과값(gradient)** 이 목적. 도함수 자체는 중간 과정일 뿐.

## 7. 브로 질문에 대한 최종 답

> **Q: "미분, 미분값, 미분식, XX의 미분" 표현들이 헷갈린다. 내가 기초가 부족한 건가?**

### A: 절대 기초 부족이 아니다. ✅

1. 한국 수학 용어 번역의 **구조적 문제**다. "미분"이라는 단어 하나에 7개 의미가 쑤셔 넣어져 있음.
2. 영어 원서를 보면 **differentiate / derivative / differentiation / differentiable**로 분리되어 헷갈림이 적다.
3. 수학 전공자들도 초심자에게 가르칠 때 **"이거 도함수입니다!"** 정정하면서 설명하는 게 일상.
4. 브로가 헷갈리는 건 **"왜 이렇게 부르지?"** 질문을 던지는 정상적 사고 증거. 기초 부족이 아니라 **관찰력의 증거**.

### 생존 전략 요약

- "미분" 등장 → §4의 **5가지 휴리스틱**으로 해독
- 가능하면 **영어 원서 병행** (용어가 명확)
- **표기($f'$, $\dfrac{dy}{dx}$, `grad`)를 보고 의미 파악**하는 습관
- 신경망 컨텍스트면 **gradient(미분값)** 라고 가정하는 게 90% 정답

## 8. 요약 / 결론

### "미분" 7종 혼돈 최종 정리표

| 문맥 신호 | 의미 | 영어 | 수학적 대상 |
|---|---|---|---|
| "미분하다" | 연산 | differentiate | 과정 |
| "미분값" | 결과값 | derivative value | 숫자 |
| "$X$의 미분" ($X$=함수) | 도함수 | derivative | 함수 |
| "미분식" | 수식 | differential equation/expression | 방정식 |
| "미분 가능하다" | 성질 | differentiable | 성질 |
| "미분학" | 학문 | differential calculus | 분야 |
| "미분 방정식" | 방정식 종류 | differential equation | 방정식 |

### 핵심 교훈

1. **기초 부족이 아니다**. 한국 수학 용어 번역의 구조적 문제.
2. 영어 원서가 용어 면에서는 더 명확 (differentiate/derivative/differentiation 분리).
3. **표기를 보고 의미를 파악하자**. "미분"이라는 단어에 의존 금지.
4. 신경망 컨텍스트의 "미분" = gradient (미분값)이 90%.
5. 헷갈리면 **"이거 도함수요, 미분값요?"** 질문하는 게 정상. 수학자도 묻는다.

### 다음 step 예고

- **step06 (수동 역전파)**: `Variable.grad`에 **미분값**을 저장. 여기서 "미분"은 gradient.
- **step07 (역전파 자동화)**: `backward()`가 자동으로 모든 변수의 미분값을 채움.
- → 이때 "미분"이라는 단어가 gradient(미분값)으로 쓰이는 경우가 대부분.
