## 1. 핵심 대비 — 근사 차수가 전략을 바꾼다

| | 경사하강법 (step28) | 뉴턴 방법 (step29) |
|---|---|---|
| f를 뭘로 근사 | **직선** (1차 테일러) | **포물선** (2차 테일러) |
| 근사식의 최소점 | 없음 (직선은 한 방향으로 무한히 감) | **있음** (포물선의 바닥) |
| 아는 것 | 방향뿐 | 방향 + **점프 거리** |
| 갱신식 | `x ← x - lr·f'(x)` | `x ← x - f'(x)/f''(x)` |
| 보폭 결정 | **임의** (lr — 사람이 정함) | **수학이 결정** (곡률로 보정) |
| 수렴 속도 | 선형 수렴 (오차 ×상수) | **2차 수렴** (오차 제곱) |

★ 브로 통찰 검증 ✓ — "경사하강 = 1차 항" 정확. 탐구 노트 28에서
`lr|∇f|²` 감소 담보를 증명할 때 쓴 게 바로 1차 테일러였다. 뉴턴은
그 증명을 2차로 올린 것.

## 2. 뉴턴 갱신식 유도 — 포물선의 바닥

현재 점 x₀에서 f의 2차 테일러 전개:

```
f(x) ≈ f(x₀) + f'(x₀)(x - x₀) + ½ f''(x₀)(x - x₀)²
```

이 근사 포물선(= f에 **접하는** 포물선 — 책 그림의 그것)의 바닥은
미분해서 0으로 두면 나온다:

```
d/dx [위 식] = f'(x₀) + f''(x₀)(x - x₀) = 0
→ x = x₀ - f'(x₀)/f''(x₀)
```

직관: 기울기 f'를 0으로 만들려면, 현재 기울기를 곡률 f''로 나눈 만큼
되돌아가면 된다. **가파를수록(f' 큼) 멀리, 굽을수록(f'' 큼) 짧게** —
스텝 크기의 물리적 의미가 lr 대신 수학에서 온다.

## 3. ★ 2차 미분의 정체 — 접촉 조건, 곡률, 그리고 원동력

이 절 전체가 브로 질문 3연타에서 도출됐다: "접한다는 게 정확히 뭔가?" →
"왜 f''가 곡률인가?" → "물리의 가속도(2차 미분)와 기하의 곡률은 관계가?"

### "접한다는 것" — 접촉 3조건

위에서 "f에 접하는 포물선"이라 했을 때 접촉의 정확한 의미 (브로 직관 검증 ✓):

접점 x₀에서 **f, f', f'' 세 가지가 동시에 일치**한다:

| 조건 | 의미 |
|---|---|
| f(x₀) 일치 | 같은 점을 지남 |
| f'(x₀) 일치 | 같은 방향 (접선) |
| f''(x₀) 일치 | 같은 휨 (2차 테일러의 설계) |

2차 테일러 전개가 정확히 이 3조건을 만족하는 포물선이다.

#### 왜 f''가 "곡률"인가 (브로 질문에서 도출)

세 층위로 쌓아보면: f = 높낮이, f' = 기울기(방향), **f'' = 기울기의 변화율**.
기울기가 변한다는 것 = 곡선이 휘고 있다는 것 — 직선은 f'' = 0(휨 없음),
급하게 꺾이는 곳은 f''가 크다. 운전 비유로 f''는 핸들을 도는 양.

기하학의 엄밀한 곡률은 "단위 호 길이당 접선이 도는 각도"로 정의되고
계산하면 κ = f''/(1 + f'²)^(3/2) — 접선 각도 θ = arctan(f')의 변화율을
호 길이로 나눈 것. **곡선이 완만할 때(|f'| ≪ 1)는 κ ≈ |f''|**라서
관용상 f''를 그냥 "곡률"이라 부른다. 또 곡률의 역수는 곡률 반지름(그 지점에
가장 밀착하는 원의 반지름) — f''가 크면 밀착 원이 작다 = 급하게 휜다.
뉴턴 갱신에서 "f''로 스텝을 나눈다"는 "휨이 급할수록 짧게 점프"로 읽힌다.

(cf. 1차 테일러(접선)는 접촉 3조건 중 앞의 2개만 만족 — 방향까지만 같고
휨은 무시. 근사를 한 차수 올린다는 것 = 접촉 조건을 하나 더 만족시키는 것.)

### 물리와의 평행 — "원동력은 2차에 있다" (브로 사변에서 도출)

브로 질문: "물리의 2계 미분 = 가속도, 기하의 2계 미분 = 곡률 — 이 둘은
관계가 있는가?" → 수학적 대상(f'')은 하나, **독립변수가 시간이냐 공간이냐가
해석을 결정**한다. 그리고 이 관점은 물리학사의 대전환 그 자체다:

- 아리스토텔레스(1차 관점): 속도가 힘에 비례 — 힘이 원동력이면 빨리 움직인다
- 갈릴레이/뉴턴(2차 관점): 힘은 **가속도**를 만든다 — 힘 없이도 등속(관성).
  **"무엇이 움직이는가(1차)"가 아니라 "무엇이 움직임을 바꾸는가(2차)"**

| | 1차 미분 | 2차 미분 |
|---|---|---|
| 물리 | 속도 (상태) | 가속도 = 힘의 현현 (상태를 바꾸는 자) |
| 기하 | 기울기 (모양의 순간) | 곡률 = 휨 (모양을 결정하는 자) |
| 최적화 | 방향만 앎 (경사하강 — lr 임의) | 점프 거리까지 앎 (뉴턴) |

1차는 정보/상태, 2차는 그것을 바꾸는 동력 — 브로 표현 "곡률을 타고 점프"는
2차 정보가 있어야만 가능한 동적 움직임을 가리킨다.

이 직관의 **실제 구현체가 모멘텀 옵티마이저**다: `v ← β·v - lr·∇f; x ← x + v`
— 물리의 관성(속도 항)을 최적화에 이식. "무게진 공이 골짜기를 구른다"는
물리 시뮬레이션 그 자체. SGD는 마찰 무한의 세계(관성 없음), 모멘텀은 물리에
가까운 세계 — 최적화 이론사가 이 직관을 실제로 밟아온 것.

보너스(문턱만): 반대 방향도 성립 — 최소작용원리에서 자연의 운동 자체가
최적화 문제다. 물리 ↔ 최적화는 대칭. 그리고 뉴턴 갱신식과 F=ma가 같은
사람 이름인 것도 상징적 — 2차 미분의 힘을 역학과 미적분 양쪽에서 다 본 사람.

## 4. 뉴턴 방법의 원래 정체 — 같은 공식, 다른 문제

뉴턴 방법의 원조는 **방정식 근 찾기**: `g(x) = 0`의 해를

```
x ← x - g(x)/g'(x)
```

로 찾는 기법 (접선이 x축과 만나는 교점으로 점프).

최적화는 "f'(x) = 0인 점 찾기"이므로 **g = f'를 대입**하면:

```
x ← x - f'(x)/f''(x)
```

즉 최적화 뉴턴 = "f'에 대한 근 찾기 뉴턴". 기하학적으로는
- 근 찾기: f의 **접선**이 x축 만나는 곳으로 점프 (1차)
- 최적화: f의 **접포물선**의 바닥으로 점프 (2차)

같은 공식이 한 층 위에서 재사용되는 구조.

## 5. 2차 수렴 — 오차가 제곱으로 줄어든다는 것

step29 데모 [1] 실측 (x₀ = 2.0, 최소점 1.0):

```
iter 0: 오차 1.0
iter 1: 오차 4.5e-01
iter 2: 오차 1.5e-01
iter 3: 오차 2.5e-02
iter 4: 오차 9.1e-04
iter 5: 오차 1.2e-06
iter 6: 오차 2.3e-12
iter 7: 오차 0        ← 기계 정밀도 도달
```

- **선형 수렴** (경사하강): 오차가 매번 상수배 (예: ×0.5) — 유효숫자가
  매번 일정 개수씩 늘어남
- **2차 수렴** (뉴턴): 오차가 매번 **제곱** (e → e² → e⁴) — 유효숫자가
  **매번 배가** (1자리 → 2자리 → 4자리 → 8자리...)

왜 제곱인가(직관): 점프 목적지는 "포물선 근사가 정확하다는 가정"하의
최적점. 근처에서는 테일러 오차 자체가 (거리)³ 이하로 줄어들어(2차 항까지
맞췄으므로 남은 오차는 3차 이상), 오차 e의 실제 최적점 보정도 e² 수준 —
그래서 다음 오차가 e²가 된다.

## 6. "수동 계산"의 의미 — f''는 아직 손으로

step29의 함수 시그니처가 증거:

```python
def f(x):  return x ** 4 - 2 * x ** 2   # 프레임워크가 1차 미분 자동
def gx2(x): return 12 * x ** 2 - 4      # ★ 사람이 손으로 유도한 f''
```

- 현재 rezero(및 dezero)의 자동 미분은 **1차까지만** 지원 (fill_grad는 f' 계산)
- f''는 f'를 다시 미분해야 함 = **고차 미분** — 3고지의 진짜 주제
- 그래서 책 제목이 "뉴턴 방법으로 푸는 최적화**(수동 계산)**" — f''만 수동
- 이 한계를 해소하는 게 step30 "최적화 자동화" → 역전파의 역전파
  (backward of backward) 구조로 2차 미분을 자동화

## 7. 실험 증거 3종 (step29 데모)

### 7.1 [2] 오버슈트 오판 사건 — 측정식도 증거가 되어버린 사건

경사하강(lr=0.1) 비교 실험에서 `|x - 1|`로 측정하니 "100,000 iters 실패,
최종 오차 2.0"이 나왔다. 오차 2.0 = x가 **-1 근처** — f가 **±1 두 개의
최소점을 가진 대칭 함수**라 첫 스텝 오버슈트(2 → -0.4)로 반대편 골짜기에
안착한 것이었다. 측정을 `min(|x-1|, |x+1|)`로 정정하니 13 iters 성공.

교훈 2가지:
- **측정식이 오판할 수 있다** — "어떤 최소점이든 좋다"가 문제의 요구였으면
  측정도 그렇게 정의해야 한다
- lr 민감성의 실증 — lr=0.1은 이 지형에서 점프가 골짜기를 통째로 넘는 크기

### 7.2 [3] 국소 최대 함정 — f'' ≤ 0 지역

x = 0.3에서 시작(f''(0.3) = -2.92 < 0, 오목 지역):

```
0.3 → -0.074 → 0.0008 → 0.0000 (정지)
```

x = 0은 f'(0) = 0인 **국소 최대점** — 뉴턴은 f'(x) = 0이면 멈추는데,
그것이 최소점이라는 보장은 없다. f'' ≤ 0 지역에서는 포물선이 위로 열려
"바닥 점프"가 아니라 잘못된 방향의 계산이 된다.

### 7.3 [4][5] 책 그림 재현 — 시각화 2장

- `output/newton_quadratic.png` — **전체 과정 연쇄**: f(x) = x⁴ - 2x² 위에
  각 스텝의 접 포물선(점선)이 차례로 그려지고 바닥으로 점프. 4번의 점프로
  최소점(빨간 별) 도달.
- `output/newton_dramatic.png` — **한 스텝의 클로즈업** (책 그림 스타일):
  f(x) = x⁴/20 - x² (극값 3개), 그림 중앙 접점에서 포물선이 완전한 U자로
  열리고, **바닥(빨간 별)이 실제 우물(회색 별)을 지나쳐 어긋나 있는 상태** —
  "근사라 아직 어긋난다, 그래서 반복한다"를 한 장에 담음. 접점 주석은
  접촉 3조건(f, f', f'' 일치) 표기.

## 8. 적합성 메모 — 선택 지도의 두 번째 좌표 (탐구 노트 27 갱신)

**뉴턴 방법 — 빛나는 경우**:
- 매끄러운(2차 미분 가능) 함수 + 좋은 초기치
- 저차원 (1~수십 차원), Hessian 계산/역행렬이 감당 가능
- 정밀도가 중요한 근접 정밀화 (2차 수렴으로 몇 스텝에 기계 정밀도)

**최악인 경우**:
- f'' ≤ 0 지역/나쁜 초기치 → 최대점이나 안장점에 갇힘 ([3] 실증)
- 고차원 (딥러닝) — Hessian n×n 행렬의 저장/역행렬 O(n³) 불가능
  (탐구 노트 27 "뉴턴 vs SGD"의 핵심 — 파라미터 수백만 개면 Hessian이 메모리 초과)
- f'' 계산 비용이 큰 함수

→ 지도 정리: **경사하강은 "저렴하고 견고하게 멀리", 뉴턴은 "비싸지만
근처에서 압도적으로 빠르게"**. 실전은 혼합(준뉴턴, 모멘텀) — 다음 좌표들.

## 10. 🎯 결론

- 뉴턴 방법 = **f를 접하는 포물선(2차 테일러)으로 근사하고 그 바닥으로 점프**.
  "접한다" = 접점에서 f, f', f''(곡률)가 동시에 일치 — 근사를 한 차수 올리는
  것은 접촉 조건을 하나 더 만족시키는 것. 원조(방정식 근 찾기)의 공식을 f'에 적용.
- 근사를 한 차수 올리는 것만으로 "방향만 아는" 전략이
  "거리까지 아는" 전략이 된다 — lr이 사라지고 f''(곡률)가 스텝 크기를 결정.
- 2차 수렴으로 근처에서는 무적 (7 iters에 기계 정밀도) — 단,
  f'' ≤ 0 지역과 나쁜 초기치엔 함정(국소 최대에 갇힘), 고차원에선 Hessian 비용 불가.
- "수동 계산" = f''를 손으로 유도해야 하는 현재 프레임워크의 한계 —
  이 한계를 뚫는 고차 미분 자동화가 3고지의 본론 (step30+).
