## 📌 왜 이 탐구를 했나

경사하강법 설명은 대부분 "gradient는 최대 상승, -gradient는 최대 하강"을
**증명 없이 당연시**한다. 이 노트는 그 당연함을 뜯어서
"방향 미분 → 내적 → 코사인"의 3단 유도로 회수하고, 이어서 gradient의
정체(무엇에게 정의되고 무엇을 만들어내는가)까지 개념 경계를 정리한다.
필요한 배경지식은 내적과 편미분 — 이미 우리가 갖고 있던 것들뿐이다.

---

## 1. 질문부터 제대로 — "방향 미분"

"gradient가 최대 상승 방향이다"를 검증하려면 먼저 이렇게 물어야 한다:

> 점 x에서 **임의의 방향 u**로 아주 조금 움직이면 f는 얼마나 변하나?

이것이 **방향 미분(directional derivative)** D_u f 이다.
"gradient가 왜 1등인가"보다 "모든 방향의 성적표는 어떻게 나오는가"가 본질 질문.

## 2. 유도 — 방향 미분은 내적이 된다

u를 단위 벡터 (u₁, u₂)로 쪼개면 f의 변화는 각 축 기여의 합:

```
D_u f = ∂f/∂x · u₁ + ∂f/∂y · u₂ = ∇f · u
```

★ 브로 자각 — "편미분의 모양새 자체가 내적의 정의적 표현과 같은 상황":
**곱해서 더하는 순간 수학적으로 내적이 되는 것**이다.
내적을 "별도로 계산하는 단계"가 있는 게 아니라, 편미분을 방향으로 조합하면
내적의 대수적 정의 (a₁b₁ + a₂b₂)와 정확히 일치한다.

## 3. 코사인 — 결정타

내적의 기하학적 의미 (θ = ∇f와 u의 각도, |u| = 1):

```
D_u f = |∇f| · cos θ
```

θ를 굴려보면 모든 방향의 성적표가 나온다:

| θ (u의 방향) | cos θ | f의 변화율 | 의미 |
|---|---|---|---|
| **0** (u = ∇f) | 1 | **+|∇f|** | 최대 증가 — gradient 방향! |
| π/2 (∇f에 수직) | 0 | 0 | 변화 없음 — **등고선을 따라 이동** |
| **π** (u = -∇f) | -1 | **-|∇f|** | 최대 감소 — 경사하강 방향! |

★ 결론: gradient 방향이 "특별해서" 1등이 아니라, **모든 방향의 변화율이
|∇f| cos θ 공식으로 결정되다 보니 θ=0이 자동으로 1등인 것.**
코사인의 최댓값이 1이므로.

직관 버전 (내적 = 정사영): u를 어떻게 잡든 ∇f에 평행한 성분만 f를 바꾸고
수직 성분은 못 바꾼다. 완전 정렬(θ=0)이 최효율.

## 4. ★ gradient의 정체 — 모든 방향미분의 "생성자"

3절의 공식이 말해주는 gradient와 방향미분의 관계:

| 개념 | 정체 |
|---|---|
| 방향미분 D_u f | 방향 u를 **하나 골랐을 때** 나오는 **스칼라** 성적표 |
| gradient ∇f | 방향을 **안 고르고 전부 담은 벡터** — 모든 방향미분의 요약 카탈로그 |

- 관계: D_u f = ∇f · u — gradient 하나 있으면 어떤 방향이든 성적표를 **뽑아낼 수 있다**.
- 즉 gradient는 방향미분들의 **생성자**(generator — "만들어내는 원천"이라는 기술 용어.
  생성자(constructor)와는 다른 단어).
- 비유: gradient는 **모든 방향의 성적표를 미리 계산해 둔 카탈로그** —
  방향 u만 들고 와서 내적하면 즉석 뽑기. 역방향은 불가 (성적표 한 장으로 카탈로그 복원 못 함).
- f' 하나가 ±x 두 방향 성적표를 압축했듯, ∇f는 **무한 개의 방향 성적표를
  벡터 하나로 압축** — 이게 gradient의 힘.

## 5. ★ 스칼라장과 벡터장 — gradient는 어디에 정의되는가

**장(field)** = 공간의 각 점마다 어떤 값을 배정한 것 (물리 전기장/자기장에서 온 개념).

| 종류 | 각 점마다 | 예 |
|---|---|---|
| 스칼라장 | 숫자 하나 | 온도/기압 지도, 로젠브락 높이 지도 |
| 벡터장 | 화살표 하나 | 바람 지도, 자기장, **gradient** |

- **gradient = 스칼라장에서 벡터장을 뽑아내는 연산.** 로젠브락 지도의 각 지점에
  화살표(그 점의 ∇f)가 하나씩 박힌 날씨 지도를 상상하면 정확한 그림.
- 코드로 보면: `rosenbrock(x0, x1) → y` = 스칼라장 샘플링, `x.grad` = 그 점의
  gradient 벡터. `fill_grad`는 스칼라장에 벡터장을 입히는 기계.
- 출력이 **벡터**인 함수엔 gradient 대신 **야코비안**(행렬)이 필요 —
  v2/step33+ 이야기이자 v1 "derivative hook 붕괴 지점".
- ★ 신경망 학습의 전체 그림 연결 (브로 도출): 손실함수 L(가중치들)은
  **수백만 차원의 스칼라장** → 그래서 ∇L이 정의됨 → 그래서 -∇L이
  "loss가 가장 빠르게 감소하는 방향" → **"학습" = 손실이라는 산을 내려가는 등반**.
  "왜 신경망 학습이 gradient 하강인가"의 답 = "손실함수가 스칼라장이기 때문".

## 6. 1변수 미분도 방향미분인가? — 브로 직관 검증 ✓

브로 상상: "접선에 화살표, x축 한쪽으로 이동 시 최대/최소로 향하는 것처럼 보인다"
→ **정확하다.**

- 1차원의 이동 방향은 **+x, -x 둘뿐** — 방향미분의 특수 사례
- f'(x) = "+x 방향으로 갈 때 변화율" = D₊ₓf. 반대 방향은 -f'(x)
- "최대 상승 방향" = f'의 **부호가 가리키는 쪽** (f' > 0 → +x, f' < 0 → -x)

즉 1변수 미분은 **선택지 2개짜리 방향미분**이고, 다차원에서 방향이 무한히
많아지면서 "그중 최고는?"이라는 질문이 생기고 그 답이 gradient.
고딩 미분 → 대학 미적분이 같은 뿌리에서 자라난 것.

## 7. 왜 경사하강법 코드에는 내적이 안 보이는가

브로 관찰: "경사하강법 예시 코드엔 편미분 값이라도 나오지, 내적 계산은 안 보인다."

답은 **증명(why)과 실행(how)의 분리**:

- 내적/코사인 → "왜 -∇f가 최대 하강인가"를 **증명**할 때 쓰는 도구 (1~3절)
- 경사하강법 코드 → 증명이 끝난 결론 "-∇f로 가면 된다"를 **실행**만 함
- 방향을 평가·비교·선택할 일이 없으니(고정적으로 -∇f) 내적은 등장할 자리가 없음

rezero 관점: `fill_grad` = ∇f를 계산하는 기계 (각 성분 = 편미분),
`gd_step` = -lr × ∇f로 이동하는 기계. 둘 다 "증명이 내장된 결론"의 구현.
수학의 증명 과정이 코드에 항상 문자 그대로 나타나지는 않는다는 좋은 예.

## 8. 갱신 식의 해부 — x ← x - lr·∇f 에 담긴 설계

경사하강법의 실행 식은 한 줄이지만, 단순함이 **왜 통하는지**가 설계의 핵심이다.

### 4가지 재료 분해

```
x_new  =  x_old  -  lr  ×  ∇f(x_old)
 현재        현재     보폭    발밑의 경사
 자리에       자리     스케일   (방향 + 크기)
 서기
```

| 재료 | 역할 |
|---|---|
| ∇f(x_old) | 현재 위치에서 잰 **발밑의 경사** — 어느 쪽이 오르막인지 + 얼마나 가파른지 |
| - (부호) | 방향 뒤집기 — 오르막 정보를 내리막 이동으로 변환 |
| lr | 보폭 크기 — gradient 벡터를 균일하게 축소 |
| = (대입) | 한 걸음 이동한 자리에 다시 서기 (다음 iteration에서 거기서 다시 경사 재기) |

### 안개 낀 하산 — greedy 전략

눈앞 1m만 보이는 산: ① 발밑 경사를 잰다(∇f) → ② 내리막으로 보폭만큼 내딛는다(-lr·∇f)
→ ③ 새 자리에서 다시 잰다 → 반복. 계획도 지도도 목적지 시야도 없이
**매 순간의 국소 정보만으로 움직이는 greedy(탐욕) 전략**. 그런데 골짜기 바닥에
안착한다 — 국소 정보의 반복이 대역 정보(최소점)에 도달하는 것.

### 보폭의 자동 적응 — gradient 크기까지 곱하는 이유

`lr × ∇f`는 gradient의 **크기**도 반영한다:

- 가파른 곳(|∇f| 큼) → 보폭 자동으로 큼 / 완만한 곳 → 자동으로 작음
- **최소점 근처(|∇f| → 0) → 보폭 자동 수렴 — 자동 브레이크**

실증 (step28 데모 iter 0): grad = (-2, 400) — x₁ 방향이 200배 가파르니 x₁이
먼저 크게 움직임 (2 → 1.6). "가파른 축부터 급하게, 완만한 축은 천천히".
단점도 같은 메커니즘에서 — 가파른 방향 기준으로 lr을 맞추면 완만한 방향은
답답해져서 rosenbrock이 기어간다 (탐구 노트 27의 조건수 이야기).

### ★ 왜 이 식이 f를 확실히 줄이는가 — 1차 테일러 한 줄 증명

2절의 도구(내적)를 회수하면 증명이 공짜로 나온다. f를 δ만 움직일 때:

```
f(x + δ) ≈ f(x) + ∇f · δ
```

여기에 δ = -lr·∇f를 넣으면:

```
f(x_new) ≈ f(x) - lr·|∇f|²
```

**lr·|∇f|² ≥ 0이므로 (∇f ≠ 0이면 양수), 한 걸음마다 f가 적어도 1차 근사
내에서 lr|∇f|²만큼 감소한다는 보장.** "왜 하필 -lr·∇f냐"의 가장 직접적인 답 —
감소를 수학적으로 담보하는 가장 단순한 선택이다. (∇f = 0이면 감소량도 0 —
정지점에서 멈춘다는 뜻이기도.)

### 이 식에 없는 것 — 관성

매 순간 발밑만 보는 greedy 방식이라 **이전 방향의 기억(관성)이 없다** — 골짜기에서
지그재그하는 이유. 여기에 물리의 관성을 얹은 것이 모멘텀 계열 개선 (탐구 노트 27의
선택 지도에서 다음 좌표). 지형 탐색에 물리 법칙이 등장하는 최적화의 묘미.

## 9. 보너스 — 이제 공짜로 이해되는 것들

- **등고선은 gradient와 수직**: θ=π/2에서 변화율 0 = 등고선(같은 값의 선)을
  따라 이동한다는 뜻. 등고선 접선 ⊥ gradient가 자동 귀결.
  (step24 벤치마크 등고선 이야기와 연결)
- **gradient 크기 = 가파름**: |∇f|가 최대 변화율 그 자체. gradient 노름이 크면
  그 지점이 가파르다.
- **안장점/정지점에서 ∇f = 0**: 모든 방향 변화율이 |∇f| cos θ = 0 — 어느
  방향도 1차적으로는 오르내리지 않는 지점.

## 10. 잡동사니 Q&A — 후속 질문 3연타

### Q1. "편미분 항들의 합 → 적분 연상?" — 반쯤 진짜다

- 차원 분석: ∂f/∂x는 [f]/[x], u는 무차원 → 항들이 같은 차원이라 **더할 수 있음**.
- "변수 개수만큼 항의 합"은 적분이 아니라 **선형 중첩** — "미분 가능 = 국소적으로
  각 축 기여를 더하는 선형 근사" (1차 테일러의 다변수 버전).
- ★ 적분 연상의 진짜 연결: 국소 방향미분을 경로를 따라 **쌓으면** 총 변화 —
  `f(도착) - f(출발) = ∫ ∇f · dl` (**선적분**, 미적분 기본정리의 다변수 버전).
  경사하강 궤적도 결국 "작은 -∇f 발걸음들이 쌓인 적분". 미분(국소) ↔ 적분(대역).

### Q2. "정사영 vs 물리 힘 합성?" — 세 가지는 다른 연산

| 상황 | 방향 | 예 |
|---|---|---|
| 물리 평행사변형법 | 여러 벡터 → **합쳐서** 1개 | 힘의 합성 |
| gradient | 스칼라장 → **뽑아낸** 벡터장 | 각 점의 편미분을 성분으로 묶음 |
| 방향미분의 정사영 | 벡터 2개 → **겹치는 성분만** 스칼라 | ∇f·u |

물리 직관이 만나는 곳은 세 번째: "힘을 이동 방향으로 분해해 유효한 일만 센다" ≡
"u 중 ∇f 방향 성분만 f를 바꾼다" — 동일한 구조.

### Q3. "gradient 어원? 사람 이름은 아니지?"

아니고 ㅋㅋ — 라틴어 **gradiens**(오르다/기울다) ← **gradus**(걸음, 단계).

```
gradus (걸음)
├── gradient — 기울기/경사
├── gradual — 점진적인
├── grade — 등급
└── 색 "그라데이션" — 색이 서서히 변함 ← 동족어!
```

영어 일상어 gradient = 철도/도로의 경사도 (10% gradient). 함수의 gradient도 같은 뜻 —
기울기를 한 벡터로 모은 것. 한국어 번역: 그냥 **기울기 벡터**.
(미분기하 용어 셋트: gradient=기울기, divergence=발산, curl=회전.
일화: Maxwell이 "gradient 대신 slope이라 하자"고 제안했다가 안 붙음.)

## 12. 🎯 결론

- "gradient = 최대 상승"은 당연한 게 아니라
  **방향미분 = 내적 = |∇f| cos θ**의 3단 유도의 결론.
- gradient는 방향미분 그 자체가 아니라 **모든 방향미분의 생성자(카탈로그)** —
  하나 저장하고 무한 방향 커버.
- gradient = **스칼라장에서 벡터장을 뽑는 연산** ("기울기"의 다차원 완성형).
  신경망 학습이 gradient 하강인 이유도 여기서 — 손실함수가 스칼라장이기 때문.
- 갱신 식 x ← x - lr·∇f는 **국소 정보만 쓰는 greedy 전략**인데
  크기 기반 자동 보폭 + 감소 담보(lr|∇f|²) + 최소점 자동 감속이 설계돼 있어
  단순하지만 견고하다.
- 1변수 미분 = 선택지 2개짜리 방향미분 (브로 직관 검증 ✓).
- 경사하강법 코드에 내적이 안 보이는 것 = 증명(why)과 실행(how)의 분리.
- 필요한 배경지식은 내적과 편미분 — 새로운 지식이 아니라
  **있던 지식의 조합으로 숨은 증명을 회수한** 탐구.
