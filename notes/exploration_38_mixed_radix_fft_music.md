## 0. 한 장 요약 — 망상은 망상이 아니었다

> **브로의 두 직관은 둘 다 정확했다. (1) 혼합 진법에는 선형대수 테마 클러스터가 실존한다 — 쌍대 공간, 기저 변환, CRT, 텐서곱, 그리고 그 정점에 FFT. (2) 음악의 7모드는 "같은 원소, 다른 시작점" = 같은 버퍼를 다른 base 위치에서 읽는 회전 뷰 — 어드레싱의 나머지 한 노브였다.**

$$\text{주소} = \underbrace{\text{base}}_{\text{모드(회전)가 돌리는 노브}} + \underbrace{\langle \text{idx},\ \text{strides} \rangle}_{\text{전치(축 재배치)가 돌리는 노브}}$$

| 브로의 느낌 | 정식 정체 |
|---|---|
| "strides가 가중치 같다" | 선형 범함수 — strides = 쌍대 공간의 원소 (노트 37 §4) |
| "진법 변환 뭔가 변환 같다" | 기저 변환 — 같은 수의 다른 전개 = 같은 벡터의 다른 좌표 |
| "혼합 진법에 선형대수 주제 있나?" | CRT/잉여류 진법, 텐서곱 분해, (혼합 기수) FFT |
| "7모드가 축교환 느낌" | 같은 버퍼의 회전 뷰 — strides가 아니라 **base 상수항**을 바꿈 |
| "스케일이 혼합 진법 느낌" | MIDI 번호 = 12진 혼합 진법, 리듬 = 시계의 음악판 |

## 1. 두 갈래의 지도 — 대수와 음악

> 브로 (2026-08-30): *"FFT와 화성학은 개인적으로 재미있게 느끼는 주제고 제대로 파보고 싶은 분야"*

이 노트는 두 갈래의 씨앗을 심어둔다:

- **갈래 A (대수)**: 혼합 진법의 선형대수 → 텐서곱 → FFT. 노트 37에서 배운 reshape/전치가 대학원 수학에서 어떤 이름으로 불리는지, 그리고 그것이 세상에서 제일 유명한 알고리즘(FFT)의 심장인 것.
- **갈래 B (음악)**: 음높이의 산수(로그 + 모듈러) → 순환군 ℤ/12 → 7모드 = 회전 뷰 → 조옮김과 모드의 구분 → 음악이론의 군론 학파.

둘은 노트 37의 어드레싱 세계관이라는 뿌리에서 갈라진다 — "같은 데이터, 다른 해석 규칙".

<a id="대수클러스터"></a>
## 2. 혼합 진법의 선형대수 클러스터 — 쌍대·기저·CRT·텐서곱·FFT

### 2.1 쌍대 공간과 선형 범함수 — strides의 정식 주민 등록

오프셋 공식 $\text{offset} = i{\cdot}s_0 + j{\cdot}s_1 + k{\cdot}s_2$는 **선형 범함수의 평가** — 인덱스 벡터에 가중치 벡터 (s₀, s₁, s₂)를 대응시키는 선형 사상. 혼합 진법의 "자리값"들이 표준 기저에 대한 **쌍대 기저 좌표**로 읽힌다. (노트 37 §4 "어드레싱의 선형대수"와 같은 재료, 이름만 더 정식.)

### 2.2 기저 변환 = 진법 변환

12진수 ↔ 10진수 변환은 "같은 정수, 다른 전개" — 벡터(기저 독립 실체)와 좌표(기저 의존 표현)의 관계 그대로. 노트 37 §7의 "수학 세계(구조) vs 구현 세계(좌표 표현)" 이중성과 동형: **진법은 수의 좌표계다.**

### 2.3 중국인 나머지 정리 (CRT) — 자리 전개와 나머지 좌표

서로소인 m, n에 대해 $\mathbb{Z}/mn \cong \mathbb{Z}/m \times \mathbb{Z}/n$ (환 동형). "혼합 진법 전개(자릿수 튜플)"과 "나머지 튜플"이 같은 대상의 두 좌표계라는 정리. 잉여류 진법(RNS)으로 DSP 하드웨어가 실제로 활용 — 큰 수 연산을 자리올림 없는 작은 나머지 연산들로 분해.

### 2.4 텐서곱 분해 — reshape의 본체

$$\mathbb{R}^{mn} \cong \mathbb{R}^{m} \otimes \mathbb{R}^{n}$$

길이 12 버퍼를 (3, 4)로 reshape하는 것은 바로 이 동형의 실현이고, 혼합 진법 오프셋 공식 `i×4 + j`가 그 좌표 공식. **reshape는 새 연산이 아니라 텐서곱 동형의 좌표 표현** — 노트 37의 "전치 = strides 재배치"와 마찬가지로, 구현 세계의 사소해 보이는 연산이 수학 세계에서는 이름 있는 구조였다는 사례.

### 2.5 FFT — reshape의 스포츠 (Cooley-Tukey, 혼합 기수)

FFT의 Cooley-Tukey 알고리즘 개요 (N = N₁N₂ 분해):

```
길이 N 신호 → (N₁, N₂) 행렬로 reshape
→ 한 축 방향으로 작은 DFT들
→ twiddle factor (회전 인자) 곱
→ 다른 축 방향으로 작은 DFT들
→ 조립
```

**"혼합 기수 FFT(mixed-radix FFT)"라는 이름 그대로** — N의 인수 분해(= 혼합 진법 자릿수)를 축 구조로 바꿔 계산 복잡도를 O(N²)에서 O(N log N)으로. 2.4의 텐서곱 분해를 산업 규모로 쓰는 것이 FFT다. DFT 행렬 자체는 단위근에서 평가한 **반데르몬드 행렬** — "시간 샘플 좌표 ↔ 주파수 계수 좌표"라는 기저 변환(2.2)이기도 하다.

## 3. 음악의 순환 구조 — 로그와 모듈러 위의 7모드

### 3.1 음높이의 산수 — 로그 + 모듈러

- 음정의 덧셈 = 진동비의 곱셈: 로그가 곱셈을 덧셈으로 바꾼다 (완전5도 + 완전4도 = 옥타브 ↔ (3/2)×(4/3) = 2)
- 12반음평균률: 반음 = $2^{1/12}$ — 로그 공간에서 등간격
- 옥타브 동치: 12반음마다 같은 음 → **피치 클래스 = ℤ/12** (모듈러 산수)

★ 음악의 산수는 "로그 취하고 12로 나눈 나머지" — 혼합 진법(마디·자리)과 모듈러(감기)의 합작.

### 3.2 다장조와 음정 패턴

- 다장조 음계 = ℤ/12의 7원소 부분집합 {0, 2, 4, 5, 7, 9, 11} (C D E F G A B)
- 음정 패턴 = [2, 2, 1, 2, 2, 2, 1] (온온반온온온반 — 합계 12, 순환)

### 3.3 ★ 7모드 = 같은 버퍼의 회전 뷰 — 어드레싱의 나머지 노브

> 브로: *"루트음 집합이... 같은 원소인데 시작점이 다른? 축교환 방식이 떠오르는데, 걍 망상인가?"*

용어 정리부터 — 브로가 그린 그림("같은 원소, 다른 시작점")은 **버금모드(relative modes)**: C Ionian, D Dorian, E Phrygian, F Lydian, G Mixolydian, A Aeolian, B Locrian — 같은 7음, 다른 으뜸음. (대조적으로 **parallel modes**(C Ionian/C Dorian/...)는 으뜸음이 같고 음이 달라진다.)

버금모드 7개는 같은 버퍼의 **회전 뷰**다:

```python
buf = ['C', 'D', 'E', 'F', 'G', 'A', 'B']   # 버퍼 pos 0..6
# 모드 k = buf[(k + i) % 7] — 같은 데이터, 시작 위치만

rolled  = buf + buf          # 이중 버퍼 트릭
dorian  = rolled[1:8]        # D E F G A B C — base만 +1
phrygian = rolled[2:9]       # E F G A B C D — base만 +2
```

- 데이터 무동, 어드레싱 규칙 교체 — 노트 37 §5 관찰자 이동의 음악판
- ★ 정확한 구분: **전치는 strides 항(선형 부분)을 재배치, 모드는 base 상수항(아핀의 평행이동)을 이동** — 어드레싱 공식의 두 노브를 각각 한 번씩 돌려본 셈
- 음정 패턴 [2,2,1,2,2,2,1]의 회전([2,1,2,2,2,1,2] = Dorian...)도 같은 순환 구조 — 음 이름 버퍼와 음정 버퍼가 같은 회전 작용을 공유

### 3.4 조옮김 vs 모드 — 두 개의 다른 군 작용

혼동하기 쉬운 두 연산 (둘 다 "이동"처럼 느껴져서):

| | 조옮김 (transposition) | 모드 회전 (rotation) |
|---|---|---|
| 하는 일 | 모든 음에 k반음 더함 | 같은 7음의 **시작점**을 음급 k칸 이동 |
| 작용하는 곳 | ℤ/12 전체 (12등분 원의 회전) | 음계 내부 순서 (7원소 순환) |
| 음 집합 | **달라짐** (C장조 → D장조는 다른 음들) | **그대로** (같은 음, 다른 으뜸음) |
| 어드레싱 노브 | 버퍼 내용 자체를 평행이동 (데이터 조작에 가까움) | base 오프셋 (순수 뷰) |

즉 조옮김은 "원(ℤ/12)을 돌린다", 모드는 "같은 7개 점 위에서 어디서부터 읽기 시작할지 바꾼다".

### 3.5 MIDI = 혼합 진법, 리듬 = 시계의 사촌

- **MIDI 번호 = (옥타브, 반음도수) 두 자리 혼합 진법**: `MIDI = 12×옥타브 + 반음도수 (+12)` — C4(가운데도) = 60 = 12×5 + 0. 노트 37 §3의 시계 (24, 60, 60)와 정확히 같은 구조
- **리듬**: (마디, 박, 분박) 체계 — 마디선을 넘는 박수 세기는 시계 산수의 음악판

### 3.6 다섯번째 원 — ℤ/12의 생성원

완전5도 = 7반음, gcd(7, 12) = 1 → 7은 ℤ/12 전체를 생성하는 원소. 다장조의 7음은 다섯번째 원 위의 **연속 7세그먼트** (F C G D A E B) — "음계 = 원의 한 조각"이라는 관점. 조직(키)들의 배치가 원이 되는 이유.

## 4. 항해 지도 — Lewin·Tymoczko·새 리만

브로의 "제대로 파보고 싶다"를 위한 정식 입구들 (음악이론에 실제로 군론·기하가 들어와 있는 학파):

- **David Lewin — "Generalized Musical Intervals and Transformations" (1987)**: 음정을 집합 위의 군 작용(단순 이행적)으로 공리화한 GIS 이론. "음정 = 군 원소"의 수학적 본거지
- **Dmitri Tymoczko — "A Geometry of Music" (2011)**: 화성·음성진행을 공간(orbifold)의 기하로 다룸. 모드·조 관계의 위상
- **새 리만 이론 (Neo-Riemannian, PLR 변환)**: 장·단삼화음 사이의 변환(병행 P, 유사 R, 도태 L)들이 군을 이룸 — 기능화성의 변형을 군론으로
- (연결고리) 노트 37의 관점: 이 학파들이 하는 일은 "같은 음 집합(데이터) 위에서 변형 규칙(어드레싱)을 다루는 것" — 브로가 아침에 직감한 것의 학문판
