<a id="한장요약"></a>
## 0. 한 장 요약 — 두 얼굴

> **내적은 두 얼굴을 가진 하나의 연산이다. (1) 계산 얼굴: 곱들의 합. (2) 의미 얼굴: 두 벡터의 정렬도(방향 일치도) 측정기.**

$$\langle v, w \rangle = \sum_i v_i w_i \quad=\quad |v|\,|w|\cos\theta$$

- 프로젝트 지도: 어드레싱 오프셋(노트 37 §4), 전치 불변(§4·노트 40), 수반 항등식(§9), VJP `vᵀJ`(노트 34), 어텐션 `QK^T`(5고지) — **전부 내적의 변주**

<a id="정의와표기"></a>
## 1. 정의와 표기 — ⟨v, w⟩가 뭐냐

**계산법 (대수의 얼굴)**: 같은 자리끼리 곱해서 전부 더한다.

```
v = (1, 2, 0),  w = (12, 4, 1)
⟨v, w⟩ = 1×12 + 2×4 + 0×1 = 20
```

**표기 3형제** (전부 같은 뜻, 취향 차이):

| 표기 | 이름 | 쓰는 곳 |
|---|---|---|
| `⟨v, w⟩` | 앵글 브래킷 | 수학·물리 — 스칼라 곱 점(·)과 헷갈리지 않아 이 노트들도 이걸로 |
| `v · w` | 점곱 (dot product) | 물리·고교 — 가장 오래된 이름 |
| `vᵀw` | 행렬 곱 표기 | 구현 세계 (NumPy: `v @ w`) — "전치해서 곱한다"는 계산법 그 자체 |

- 1차원(스칼라)에서는 내적 = 그냥 곱셈 (곱 하나, 합 필요 없음) — 내적은 곱셈의 n차원 확장

<a id="정렬도"></a>
## 2. 직관 펌프 — 정렬도와 그림자

**의미 얼굴**: ⟨v, w⟩ = |v||w|cosθ — "길이×길이×사이각". 즉 **두 벡터가 얼마나 같은 방향을 보나**:

```
같은 방향 (θ=0):    ⟨⟩ = |v||w|     최대     "완전 정렬"
수직 (θ=90°):       ⟨⟩ = 0                   "무관 — 서로 그림자 못 남김"
반대 방향 (θ=180°): ⟨⟩ = -|v||w|    최소     "완전 반대"
```

숫자로 체감 (단위 벡터):

```
(1, 0)·(1, 0) =  1    같은 방향
(1, 0)·(0, 1) =  0    수직
(1, 0)·(-1, 0) = -1   반대
(1, 0)·(1, 1)  =  1   부분 정렬 (cos 45° = 0.707... 길이 √2 곱하면 1)
```

**그림자 해석**: v·w = "v를 w 방향에 **정사영(그림자)시킨 길이** × |w|" — 내적은 한 벡터가 다른 벡터 방향으로 얼마나 기여하는가.

<a id="어드레싱"></a>
## 3. 우리 문맥 1 — 어드레싱 오프셋

노트 37 §4의 그 공식이 내적이었다:

$$\text{offset} = \langle \text{idx},\ \text{strides} \rangle$$

- idx (1,2,0) · strides (12,4,1) = 20번 칸 — "인덱스에 strides라는 **가중치**를 곱해 합친" 가중합
- 어드레싱이 선형 사상(아핀)이라는 말 = 오프셋이 인덱스의 선형 함수라는 말 = 내적이라는 말 — 셋 다 같은 진술

<a id="순열과내적"></a>
## 4. 우리 문맥 2 — 순열과 내적 (같이 이사)

전치가 왜 같은 칸을 찾는가 (노트 37 §4·노트 40):

$$\langle P\,\text{idx},\ P\,\text{strides} \rangle = \langle \text{idx},\ \text{strides} \rangle$$

- 성분 뷰: P를 양쪽에 같이 적용하면 곱 vᵢwᵢ들이 **쌍으로 이사** — 항 집합 {12, 8, 0}이 순서만 바뀜 ({0, 8, 12}), 덧셈은 순서 무관 → 합 불변
- 이것이 "순열(전치)은 데이터를 안 건드린다"의 대수적 심장

<a id="수반항등식"></a>
## 5. 우리 문맥 3 — 수반 항등식

노트 37 §9의 그 식 — 전치의 본질:

$$\langle A^T y,\, x \rangle = \langle y,\, Ax \rangle$$

- "왼쪽에서 물으면 오른쪽에서 물은 것과 같다" — 계산하기 편한 쪽으로 **옮겨 담기**
- 유도의 핵심 한 걸음: 유한 합의 순서 교환 (성분 전개 — 노트 37 §9 참조)
- 대칭성의 특수 케이스: ⟨v, w⟩ = ⟨w, v⟩ (A 없이 둘 자리만 바꾸는 것도 성립)

<a id="행렬판"></a>
## 6. 행렬 판 — 내적의 가족 확장

`vᵀw` 표기가 보여주듯, 내적은 행렬 곱의 가장 작은 단위. 크기에 따라:

| 곱 | 결과 | 의미 |
|---|---|---|
| 벡터ᵀ × 벡터 | 스칼라 | **내적** (이 노트의 주인공) |
| 행렬 × 벡터 (`A @ v`) | 벡터 | **내적 여러 개** — A의 각 행과 v의 내적을 모은 것 |
| 행렬 × 행렬 (`A @ B`) | 행렬 | **내적의 표** — A의 각 행 × B의 각 열, (i,j)칸마다 하나씩 |
| `Q Kᵀ` (어텐션) | 행렬 | 모든 질문×모든 키의 정렬도 표 — 5고지에서 만날 내적의 산업 규모 |

- ★ 행렬곱 = "내적을 격자로 깐 것" — 하나의 연산을 크기만 바꿔 굴리는 것 (텐서곱 언어로는 contraction, 노트 38 §2)

<a id="실전얼굴"></a>
## 7. 실전 얼굴들 — 유사도·공분산·거리·직교

- **코사인 유사도**: 내적을 두 길이로 나눔 (cosθ만 남김) — 검색·추천·임베딩의 표준 유사도. "질문 벡터와 가장 정렬된 문서 찾기" = 내용 기반 검색의 원리
- **공분산**: (평균 뺀 벡터)들의 내적 ÷ n — 통계학의 내적. 공분산 행렬 = 내적의 표 (PCA의 심장)
- **거리와의 관계**: $\|v - w\|^2 = \|v\|^2 + \|w\|^2 - 2\langle v, w \rangle$ — 유클리드 거리와 내적은 서로 번역 가능 (피타고라스 정리의 다른 쓰기)
- **직교의 정의**: ⟨v, w⟩ = 0 ⟺ 수직 — "수직"이라는 그림 개념의 **대수적 정의**가 내적 0. 기하가 사라져도(고차원) 직교는 성립하는 이유

<a id="공리와확장"></a>
## 8. 공리와 확장 — "다른 내적도 있다"

내적이 되기 위한 최소 조건 (공리):

1. **대칭**: ⟨v, w⟩ = ⟨w, v⟩
2. **선형**: ⟨av + bw, u⟩ = a⟨v,u⟩ + b⟨w,u⟩
3. **양정**: ⟨v, v⟩ ≥ 0, 등호는 v = 0일 때만

- 이 공리만 만족하면 다 내적 — 같은 기하(길이·각도·직교)가 다른 공간에 생김
- 대표 확장: **함수 공간** ⟨f, g⟩ = ∫f(x)g(x)dx — 함수의 내적. 푸리에 급수(노트 38 §2.5)가 이 내적으로 직교 기저(삼각함수)를 분해에 쓰는 것 — "FFT = 함수 공간에서 직교 좌표축으로 기저 변환"이 여기서 성립

- Q3. 수반 항등식 손검증: A=[[1,2],[3,4]], x=(1,0), y=(0,1)로 ⟨Aᵀy, x⟩ = ⟨y, Ax⟩ 양변 계산
- Q4. `np.array([[1,2],[3,4]]) @ np.array([1,1])`의 결과를 "행마다 내적"으로 예측 후 실행
