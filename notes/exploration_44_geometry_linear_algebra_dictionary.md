| 면적·부피 | **행렬식(determinant)** det | 선형변환의 부피 배율, 부호는 뒤집힘 |

| 회전(rotation) | **회전 행렬(rotation matrix)** | `[[cosθ, -sinθ], [sinθ, cosθ]]` — 수 모음의 첫 기하 등장 |
| 거울 반사 | **반사 행렬(reflection matrix)** | det = -1 (부피 보존, 방향 뒤집힘) |

| 직각 | **내적 = 0** | 직교의 대수적 정의 |
| 뾰족함 / 주축 | **고유값·고유벡터(eigenvalue/eigenvector)** | 변환 후에도 방향이 안 바뀌는 특별한 축 |
| 기울기 | **그래디언트(gradient)** | 경사하강법 — 딥러닝 학습의 심장 |
| 휨 (곡률) | **헤시안(Hessian)** | 대각 = 자기 축의 휨, 비대각 = 변수 간 비틀림 |
| 무게중심(centroid) | **평균(mean)** | 데이터의 중심 = 점들의 무게중심 |
| (무늬의 규칙성) | **행렬 구조·대칭** | §3 무늬 도감 — 대칭행렬=선대칭, 토블리츠=벽지 등 |

## 1. 오묘함의 해소 — 수 모음이 어떻게 기하가 되나

> 브로: *"2D 행렬은 사실 수를 모아둔 것인데 기하와 연결된다는 게 오묘하다"*

**답: 수 체계 자체가 기하의 언어로 발명되었기 때문.**

- 데카르트의 좌표(1637): 점을 수 쌍 (x, y)으로 **번역** — 이 순간부터 기하 문제가 대수 문제가 됨. "원이 뭔가" = "x² + y² = r²을 만족하는 점들"
- 역방향도 성립: 수의 배열(행렬)에 **좌표를 먹이면** 움직임(변환)이 나옴 — 행렬 × 벡터 = "격자를 이렇게 비틀어라"는 규칙의 수 표기
- 그러니 "수 모음이 기하를 낳는" 게 기적이 아니라 **같은 것의 두 표기** — 노트 37의 "구현(버퍼) vs 수학(선형 사상)" 이중성과 같은 층위:
  - 수 모음 = **표현** (implementation)
  - 공간의 변환 = **의미** (semantics)
- 이중성이 오묘하게 느껴지는 건 두 층을 왕복하는 습관이 아직 덜 뱄기 때문 — 대응 사전이 그 왕복의 지도

## 2. 대응 상세 — 측정 3종 · 변환 4종 · 심화 3종

### 측정의 3종 (브로가 이미 주워들은 것 +)

**길이 → 노름**: 피타고라스 정리의 일반화. ‖v‖ = √(Σvᵢ²). "얼마나 큰가"를 하나의 수로.

**각 → 내적**: ⟨v,w⟩ = ‖v‖‖w‖cosθ. 내적 하나로 각을 재고(역산), 직각도 판정(=0), 그림자 길이도 계산(사영) — 노트 41 "내적 = 정렬도 측정기"의 기하 원류.

**면적·부피 → 행렬식**: det(A) = 선형변환 A가 단위 정사각형/정육면체를 몇 배로 부풀리는가. 2D 회전행렬의 det = 1 (면적 보존 — 늘리지도 뭉개지도 않음), 반사의 det = -1 (크기 보존, 방향 뒤집힘). "부피 배율" 관점이 핵심.

### 변환의 4종 (기하 직관의 대수화)

**평행이동 → 벡터 덧셈**: 점을 v만큼 밀기. 삼각형 법칙(이어붙이기) = 평행사변형 법칙(같은 출발점).

**닮음 → 스칼라 곱**: 원점 중심으로 k배 확대/축소. 모든 각이 보존됨 (닮음의 정의).

**회전 → 회전 행렬**: R(θ) — 열벡터가 회전 후의 기저 축. cos/sin이 들어가는 이유는 단위원의 좌표가 cos, sin이기 때문. det = 1.

**반사 → 반사 행렬**: 특정 축 기준 거울. det = -1. 회전·반사와 그 조합 = **직교행렬(orthogonal matrix)** — 길이와 각을 보존하는 선형변환 전부.

### 심화 대응 3종

**그림자 → 사영**: v의 w 방향 그림자 = (⟨v,w⟩/‖w‖²)w. 최소제곱 회귀 = "데이터를 모델 공간에 직교 투영" — 통계의 회귀가 기하의 그림자.

**★ 투영 = 최소제곱 — "수선의 발"의 성인 버전** (브로 "투영과 회귀가 이어진다고?" — 2026-09-04):

초등 기하의 정리 *"점에서 직선까지 가장 짧은 거리는 수직으로 내린 것(수선의 발)"*이
회귀의 본체다:

```
        y (실제 데이터)
        *
        |  <- 잔차(오차) — 이 길이가 최소가 되게!
        |  90도로 수직!
        *---------  <- 회귀선 (모델이 만들 수 있는 점들의 세계)
       y_hat (수선의 발 = 투영점 = 예측값)
```

- 회귀 = "데이터 y를 모델 공간 위의 점으로 표현할 때 오차 최소화"
- 오차 최소 = y에서 공간까지 **거리 최소** = 그 점은 직교 투영점(수선의 발) — 오차 벡터가 공간에 수직
- 이름이 "최소**제곱**(least squares)"인 이유: 거리 = √(Σ 오차²)이라 거리 최소화 =
  **오차 제곱합 최소화**와 같음 (루트는 단조) — MSE가 제곱인 이유가 유클리드 거리
- 딥러닝 연결: 학습(손실 최소화)도 "정답 벡터와의 거리를 줄이는 일" — 이 그림의 연장선

**뾰족함 → 고유값**: 변환을 여러 번 물려도 방향이 안 바뀌는 축(고유벡터)과 그 축의 늘어남 배율(고유값). 타원의 주축. 행렬을 거듭 곱할수록(A^k, k→∞) 고유값이 큰 축이 지배함 — 멱법(power iteration)과 PageRank의 원리.

> ★ 용어 구분 — **뾰족함(sharpness) ≠ 볼록함(convexity)**: convexity는 접시 안쪽처럼 **휜 방향이 일정한 성질** (아래로 볼록/위로 볼록 — 최적화에서 "볼록 함수"의 그것), 뾰족함은 **늘어남이 방향마다 다른 정도** (이방성, anisotropy). 고유값이 말하는 것은 후자 — 어느 축으로 얼마나 길쭉한가. 타원의 주축 길이가 고유값이다.

**무게중심 → 평균**: 점들 v₁..vₙ의 무게중심 = (v₁+...+vₙ)/n = **표본평균**. 데이터 중심이라는 통계 개념의 기하 원류.

<a id="무늬도감"></a>
## 3. 행렬 무늬 도감 — 구조와 도형의 대칭

> 브로 질문에서 출발 — *"행렬에 `/`, `\`, X자 말고도 요소가 등장하는 무늬가 있고,
> 패턴을 보고 뭔가 알 수 있다고 했잖아? 초등 기하 대응은?"*

### 무늬 도감

| 무늬 | 생김새 | 의미 | 어디서 만나나 |
|---|---|---|---|
| **대각** | `\` (주대각선) | 섞임 없음 — 변수 독립 | x²+y²의 Hessian (3패턴) |
| **반대각** | `/` | 자리바꿈 결합 (x↔y 교환) | 반사 변환 |
| **삼각** | `\` 아래만 | 의존이 **한 방향** (x₂는 x₁에 의존, 역은 아님) | 전진 대입, DAG |
| **밴드(띠)** | `\` 굵은 띠 | **이웃끼리만** 결합 | convolution |
| **토블리츠** | 대각선 방향 동일 값 | **어디서나 같은 규칙** (이동 불변) | conv 커널, 신호 처리 |
| **블록** | 섬들 | 변수 그룹별 분리 | 서브그룹핑, 모듈 구조 |
| **조밀** | 빽빽 | 전부 섞임 | **완전연결층 (Linear)** — 4고지 |
| **희소** | 대부분 빈칸 | 대부분 독립 | 노트 34 실증 (0이 아닌 성분 0.5%) |

- ★ 표기 주의: 행렬의 **주대각선은 `\` (왼쪽위→오른쪽아래)**, `/`는 **반대각(anti-diagonal)** —
  대화 중 `/`로 오기해서 브로가 정정 (2026-09-04)
- ★ 무늬의 효용: **무늬가 좋을수록 계산이 싸짐** — 밴드는 빠르고, 삼각은 순서대로 풀면
  되고(O(n²)), 토블리츠는 FFT와 만나고(노트 38 예고), 조밀은 비쌈. "무늬 = 계산 난이도의 지도"
- 무늬의 근원: **함수가 변수를 어떻게 섞는가** (노트 34·35 "섞음의 패턴 = 야코비안 희소 패턴")

### 무늬의 대칭 — "도형의 대칭" 단원과의 대응

무늬의 규칙성은 전부 초등 기하의 대칭이야:

| 행렬 구조 | 초등 기하의 대칭 | 이미지 |
|---|---|---|
| **대칭 행렬** (Hessian!) | **선대칭** — 대각선을 축으로 접으면 딱 맞음 | 종이접기 (Schwarz 정리가 접는 손) |
| **토블리츠** | **평행이동 대칭** — 무늬를 옆으로 밀어도 같음 | 벽지/줄무늬 |
| **순환 행렬** | **회전 대칭** | 노트 38의 모드 회전과 연결 |
| **반사 행렬** | 거울 대칭 | det = -1 |

> **행렬의 무늬 = 무늬의 대칭성** — 초등학교 "선대칭 도형 찾기"가 자라면 "대칭 행렬 판정".
> Hessian이 대칭인 건 수학이 종이를 접어준 것(Schwarz), conv가 싼 건 벽지 무늬처럼
> 어디서나 같아서(토블리츠) FFT로 접을 수 있기 때문.

**★ 여기서 Schwarz는 사람** (브로 "뭐라고 읽나? 뭐 하던 분?" — 2026-09-04. 위 표의 "종이접기(Schwarz)" 직후라 여기 두었음):

- **슈바르츠** (Karl Hermann Amandus Schwarz, 1843-1921, 독일 수학자) —
  독일어 Schwarz = "검은색" (슈바르츠실트의 그 철자)
- 대표 업적 **코시-슈바르츠 부등식** |⟨v,w⟩| ≤ ‖v‖‖w‖ — "정렬도가 1을 못 넘는다" (노트 41 세계)
- 우리가 쓴 **슈바르츠 정리** = 혼합 편미분의 순서 교환 가능성 (∂²f/∂x∂y = ∂²f/∂y∂x) —
  sin·cos Hessian 실험에서 hyx == hxy로 실증한 그 대칭
- 사족: 이 정리는 프랑스 **클레로**(Clairaut, 1731)가 먼저 증명 — "클레로 정리"라고도 불림.
  한 정리에 여러 이름이 붙는 수학의 흔한 풍경

<a id="연결지도"></a>
## 4. 우리 관심 주제와의 연결 지도

| 기하 개념 | 우리가 만난 곳 |
|---|---|
| 각 (내적) | 노트 41 (코사인 유사도, QKᵀ) / 어텐션의 정렬도 |
| 휨 (헤시안) | 이슈 45 투어 3패턴 — 대각=자기 축 휨, 비대각=변수 간 비틀림 (x²+y² 대각만 = 변수 독립) |
| 대각화 | 주축 변환 — PCA(공분산의 고유분해), 4고지 후반 실전 등장 예정 |
| 기울기 (그래디언트) | 경사하강법 — 노트 28 "미분 기계가 처음으로 일을 한다" |
| 부피 (행렬식) | 야코비안의 det — 확률변수 변환 시 밀도 보정 (노트 34 확장, 통계의 change of variables) |
| 그림자 (사영) | 최소제곱/회귀 — 4고지 loss 최적화의 기하 관점 |
| 회전 | 노트 37 전치(NCHW↔NHWC)의 이웃 — 좌표계 갈아끼우기 |
| 무늬 (희소 패턴) | 노트 34·35 (섞음의 패턴) / §3 무늬 도감 — 대칭·밴드·토블리츠 |

**"곱 = 강한 연결, 덧셈 = 약한 연결"(이슈 45)의 기하 재해석**: 비대각 성분은 두 변수 축을 잇는 "대각선 방향"의 관계 — 대각선이 비인접 꼭짓점을 잇듯, 비대각은 서로 다른 변수를 잇는다. 대각만 있는 행렬 = 각 축이 자기 일만 보는 독립 세계.
