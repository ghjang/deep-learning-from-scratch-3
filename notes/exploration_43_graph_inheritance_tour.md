<a id="한장요약"></a>
## 0. 한 장 요약

- **함수 5종 관찰**: 부호 참조(abs)는 값 복사로 2계 단결, 상수형(identity)은 그래프 동형인데 값의 역사가 다름, 순환(sin)은 재료 2주기로 선형 성장, 폭증(tanh)은 곱셈 분기 때문에 재사용 전략으로도 지수, 분리합(x²+y²)은 대각만
- **3패턴 법칙**: Hessian의 어떤 성분이 채워지는가 = 미분식이 그 변수를 참조하는가. 참조는 곱에서만 태어난다 (덧셈은 약한 연결)
- ★ **상속 구조**: k계 그래프는 이전 그래프 전체가 아니라 "참조된 변수 → 그 태생 함수" 사슬만 흡수 — 함수 객체는 복제가 아니라 같은 id로 재참조
- **seed 법칙**: 씨앗 수 = backprop 호출 횟수 (다변수 무관 — 씨앗은 출력 쪽 dy/dy=1)

## 1. 투어 방법론 — 예측·관찰·채점 사이클

각 스톱마다: **브로가 먼저 예측** (값/그래프 모양/2계 운명) → 관찰 (plot_derivatives 도우미) → 채점 → 이슈 45 코멘트 기록.

- 예측이 빗나간 곳이 가장 큰 학습 포인트가 됨: identity "0에서도 0" 오답 → 상수형 vs 부호 참조형의 본질 체감 / tanh 두 모드 g3≠ 예상 밖 → 부동소수점 (이슈 53)
- "눈으로 직감 → 계산으로 확인" 워크플로 (브로 — Stop 4에서 스스로 도달)

<a id="함수5종"></a>
## 2. 함수 5종 관찰 종합

| Stop | 함수 | 유형 (노트 32) | 핵심 발견 |
|---|---|---|---|
| 1 | abs(x) | 부호 참조형 | derivative = np.sign(x.data) — **값 복사**라 x가 gx 그래프에 실종 → 2계 None. 무명 `<1>` 노드 = 값 복사의 흔적 |
| 1.5 | identity(x) | 상수형 | abs와 **그래프 동형**(리프 1 + Mul)이나 값의 역사 다름 — 0에서도 1 (미분 불가 지점 개념 자체가 없음) |
| 2 | sin(x) | 순환형 | 값 4주기 / **재료 2주기** (부호가 Neg로 흡수) / 층별 새 노드 4개 고정 → 총 그래프 **선형 성장** |
| 3 | tanh(x) | 폭증형 | ×3 지수 성장. 재사용 모드도 Tanh 1개 유지에도 **여전히 지수 — 곱셈 분기가 공범**. 두 모드 g3/g4 미세 차이 (부동소수점) |
| 4 | x²+y² | 다변수 분리합 | gx = 2x에 y 부재 → **대각만** 채워짐 |

### 스톱별 하이라이트 3종

**abs 0지점의 함정**: |x|는 x=0에서 미분 불갠데 autodiff는 np.sign(0)=0을 조용히 반환. 수치미분(중앙차분)도 짝함수 대칭으로 0 → **gradient check가 통과해버리는 사각지대**. rezero 고유 아님 — PyTorch/JAX/TF 모두 sign 기반 subgradient 관례.

**sin의 "지방 노드"** (브로 관찰): 값이 1인 무명 리프 5개가 전부 Mul로 — 1 곱셈들. symbolic 미분이면 `1·x → x`로 축약될 것들이 autodiff는 계산 이력으로 정직하게 기록. 컴파일러 언어로 상수 폴딩/항등원 제거 최적화 패스 부재 — torch.compile이 하는 일의 영역.

**"값 같고 이력 다름"**: sin 4계 g4 = y와 값이 소수점 아래까지 같아도 별개 노드. abs/identity는 그 반대("구조 같고 역사 다름"). 값과 그래프는 직교하는 두 축.

<a id="3패턴법칙"></a>
## 3. 다변수 3패턴 법칙 — 곱은 강한 연결, 덧셈은 약한 연결

| 함수 | 구조 | Hessian 패턴 | 이유 |
|---|---|---|---|
| x²+y² | 분리합 (Add만) | 대각만 | Add의 derivative는 상수 1 — **형제를 안 봄** |
| x·y | 순수 곱 | 비대각만 | gx = y가 y를 직접 참조하되 x는 불참조 |
| sin(x)·cos(y) | 감싼 곱 | 전부 | 곱의 형제 참조(비대각) + 감싼 함수의 자기 입력 재참조(대각) |

> **법칙: k행의 어떤 열이 채워지는가 = g(k-1)의 미분식이 그 변수를 참조하는가.
> 참조는 곱 구조에서만 태어난다.** (브로 직관 "곱 = 강한 연결, 덧셈 = 약한 연결"이 출발점)

- None ≠ 0 재확인: 수학의 Hessian은 모든 성분이 정의되지만 autodiff는 **참조 사슬이 닿는 성분만** 계산 (노트 36 §8 풀이 3의 확정판)
- 실증 방법: `_iter_graph_vars(gx)`로 gx 그래프의 변수 직접 확인 (x²+y²의 gx에 y 부재)

<a id="상속구조"></a>
## 4. ★ 그래프 상속의 구조 — 흡수 법칙과 객체 동일성

> seed 출처 구분(seed_border) 작업 중 발견 — "그래프는 항상 자란다"(노트 36 §8)의 메커니즘 해부.

### 3분할 — 전체 / 새 / 물려받은 것 (x² 실험)

```
       그래프 전체   새로 등장   이전 계층에서 물려받은 것
y          1           1              0
g1         3           3              0     ← y의 함수(Pow)를 안 품음
g2         5           5              0     ← g1의 함수도 안 품음
g3         7           5              2     ← g2의 Mul 2개를 물려받음
```

### 흡수 법칙

> **k계 그래프는 이전 계층 그래프 전체가 아니라 "derivative가 참조한 변수 → 그 변수의 태생 함수" 사슬만 흡수한다.**

- 재참조의 경로: chain rule이 형제 변수/입력을 요구(Mul 형제 참조) → 그 변수의 creator(함수)가 역순회로 따라 올라옴
- x²의 g1이 y의 Pow를 안 품는 이유: d(x²)/dx = 2x¹ 계산에 y의 Pow 노드가 불필요 — 식이 x만 참조

### 객체 동일성 — 복제가 아니라 같은 인스턴스

- `g1 ∩ g3 = 0개`, `g2 ∩ g3 = 2개` (id 집합 교집합) — g3의 Mul 2개는 **g2에서 태어난 바로 그 Function 객체** (id 동일)
- 시각화의 무복제 병합(같은 id = 같은 박스)이 정확한 이유: 객체 동일성이 그대로 그래프 구조
- "seed에 이르는 경로 전부가 공유된다"(초기 직관)는 오답 — **참조된 사슬만 공유**. tanh(자기 참조)는 옛 출력을 계속 참조해 옛 함수가 계속 흡수 → 지수 폭발의 구조적 원인

### all vs last 미스터리의 해답

- all의 각 층 함수 수 = 그 계에서 **새로 등장한** 함수만 (primary 배치) — x² 3계: 층에 5개
- last = g3 그래프 **전체** (물려받은 2 포함) = 7개
- last에 seed 3개가 보이는 것도 동일 구조 — g3의 참조 사슬을 따라 올라가다 세 시점의 씨앗을 전부 만나는 것

<a id="seed법칙"></a>
## 5. seed의 법칙

- **씨앗 수 = backprop 호출 횟수** — 호출당 정확히 1개 (출력 쪽 dy/dy = 1이라 다변수·입력 수 무관)
- 다변수 1계: 씨앗 1개가 갈라져 gx/gy로 흐름 (서브그룹 밖 공유 재료로 배치되는 이유)
- 2계 다변수: backprop(z) + backprop(gx) + backprop(gy) = 씨앗 3개
- 출력이 여러 개인 세계(야코비안)에서만 씨앗이 "항등행렬"로 확장 — dezero/v2는 출력 1개 전제로 배제 (노트 34·36 참조)
- 시각화: seed_border 옵션 — 테두리 황금각 팔레트(1계 gold 고정) + last 모드 seed1/2/... 라벨 (씨앗 2개 이상일 때만)

## 6. 부록 — 브로 혼동 포인트와 도구 개선

### 혼동 포인트 4종 (재방문용 — 이슈 54에서 완전판)

1. "seed에 이르는 경로 전부가 공유된다" → 오답: **참조된 사슬만**
2. "seed는 변수마다?" → **호출당 1개** (출력 쪽)
3. all 층 수 vs last 전체 수 → **새 것만 vs 전체**
4. last의 seed 3개 → 공유가 아니라 **이력의 흡수**

### 도구 개선 요약 (이슈 45 산출물)

- `derive(y, x, order)` / `plot_derivatives(mode: Literal['all','last'])` — 스크립트 1줄화 (이슈 52)
- 층 라벨 `< forward >` / `< Nth backward >` (show_labels), last도 층 박스+라벨
- seed_border (테두리 팔레트 + last 라벨) — 농도(투명도)안은 시각 구분 불가로 폐기
- Graphviz 함정 2종: 중첩 cluster 부모 라벨 자식 반복 렌더링 (`label=""`로 차단), 인용 없는 `#` 주석화 (헥스는 따옴표)
- `_render_dot` 공통 파이프라인 추출
